# AnswerBook

Опросы с открытыми вопросами, учебные курсы с теорией и тестами, личные профессии и прогресс. React + TypeScript + Capacitor, без бэкенда и регистрации.

Текущая Android-версия — **1.33**. В каталоге 28 тем с 738 открытыми вопросами и 26 курсов по 8 направлениям (277 блоков, 554 задания). Направления можно сворачивать. Все материалы встроены в APK.

Добавлены свои темы и вопросы, светлая и тёмная темы, работа над ошибками, серия занятий, итоги недели, заморозки, монеты и постоянное открытие курсов за монеты. Правила экономики — [docs/economy.md](docs/economy.md). Рекламные видео пока представлены недоступной заглушкой, реальные платежи отсутствуют. В профиле доступны офлайн-политика конфиденциальности и поддержка.

Классический дизайн 1.25 сохранён в [design-history/classic-1.25](design-history/classic-1.25/README.md); история обновлений оформления — [src/design/README.md](src/design/README.md).

## Запуск

В новом PowerShell (Node.js 24 и npm):

```powershell
cd C:\MyApps\MyProjects\BackendAnswerBook
npm.cmd install
npm.cmd run dev
```

Откройте напечатанный Vite адрес. Если PATH не обновился, используйте `C:\MyApps\Nodejs\npm.cmd` вместо `npm.cmd`.

## Возможности

- Выбор одной или нескольких тем, выбор всех тем.
- Навигация между вопросами, свободный текст, пропуск вопросов.
- Сохранение тем, ответов и позиции на устройстве: Preferences в Android, localStorage в браузере.
- Документ по темам, редактирование ответов, новый опрос с подтверждением удаления.
- Копирование текста, скачивание UTF-8 `.txt`, PDF через диалог печати. Выберите «Сохранить как PDF»; при необходимости отключите колонтитулы браузера.
- Мобильный интерфейс и отдельное оформление для печати.

На телефоне интерфейс использует компактную верхнюю панель, сворачиваемые направления с темами в одну колонку и закреплённый под шапкой блок запуска теста. Список вопросов и сохранение конспекта открываются в нижних выдвижных панелях. Результаты сворачиваются по темам; печать и текстовый экспорт включают все ответы, независимо от того, какие темы раскрыты на экране. Десктопная вёрстка сохраняется на широких экранах.

Ответы хранятся локально и не отправляются в ленту обновлений. Очистка данных приложения, удаление приложения или очистка хранилища браузера удаляет прогресс. Смена домена создаёт отдельное браузерное хранилище. Важные ответы нужно выгружать. При ошибке сохранения показывается предупреждение.

## Android и офлайн

Android-проект находится в `android/`, идентификатор приложения — `ru.sluchaino.answerbook`. В APK включены интерфейс, шрифты, 738 открытых вопросов и 26 учебных курсов с 554 заданиями: первое прохождение возможно без интернета. Android 7.0 и новее (API 24+).

При запуске, возврате в приложение и восстановлении соединения автоматически проверяется JSON-лента:

```text
https://raw.githubusercontent.com/Sluchaino/AnswerBook/main/src/data/questions.json
```

Загруженный список проверяется на корректность и сохраняется на устройстве. При ошибке сети, неверном JSON или ошибке записи используется прежний список. Обновления доступны на экране выбора тем. Начатый опрос сохраняет собственную копию вопросов, поэтому обновление не меняет формулировки и порядок уже во время прохождения. При возвращении к выбору тем и новом запуске используется актуальный список.

Чтобы добавить вопросы без выпуска нового APK, измените `src/data/questions.json`, проверьте сборку и отправьте изменение в ветку `main` GitHub. Приложение загрузит файл при следующей успешной проверке. GitHub/CDN может обновлять файл с небольшой задержкой. Сервер C# для этой загрузки не нужен. Для собственного хостинга задайте `VITE_QUESTIONS_URL` в `.env` **до сборки APK**; адрес должен поддерживать HTTPS и CORS. Это публичный список вопросов, секреты в него помещать нельзя.

Системная кнопка «Назад» возвращает к предыдущему вопросу, затем к темам; с экрана результатов возвращает к ответам. В начале приложения сворачивает его. Текстовый документ передаётся через системное меню «Поделиться», PDF — через Android Print Framework («Сохранить как PDF»).

```powershell
# Пересобрать веб-часть и скопировать её в Android
npm.cmd run android:sync
# Открыть проект в Android Studio
npm.cmd run android:open
# Создать отладочный APK
npm.cmd run android:apk
```

APK с номером версии: `artifacts/AnswerBook-1.33-mobile.apk`. Скрипт также сохраняет рядом JSON с версией, временем сборки и SHA256. Исходный результат Gradle: `android/app/build/outputs/apk/debug/app-debug.apk`. Это отладочная сборка для установки и проверки; перед публикацией в RuStore нужна release-сборка с постоянным ключом подписи.

Android всегда использует отдельную мобильную компоновку из `src/mobile.css`, независимо от ширины WebView и ориентации телефона. В браузере эта компоновка включается по размеру окна. Логика вопросов, сохранение ответов и фирменный стиль общие. Номер установленной Android-версии виден вверху главного экрана. При обновлении интерфейса увеличивайте `versionCode` и `versionName` в `android/app/build.gradle`, выполняйте `npm.cmd run android:apk` и устанавливайте новый APK поверх предыдущего приложения. Обычная перезагрузка приложения обновляет вопросы, но не встроенный интерфейс.

Для сборки нужны JDK 21, Android SDK Platform 36 и Android Build Tools. В текущем рабочем окружении JDK 21 находится в `.tools/jdk-21` (исключён из Git). Скрипт `android:apk` находит его автоматически, SDK — через `ANDROID_HOME` / `ANDROID_SDK_ROOT` либо стандартную папку пользователя. На другом компьютере установите зависимости и задайте `JAVA_HOME` и `ANDROID_HOME`. В Android Studio выберите JDK 21 в Settings → Build Tools → Gradle → Gradle JDK, если Studio выбрала собственный JDK 25.

Офлайн-запуск реализован в Android-приложении через файлы, включённые в APK. Для открытия веб-сайта в браузере нужен доступ к его хостингу. Проверки логики обновлений: `npm.cmd test`.

## Добавление вопросов

### Личный кабинет и профессии

В разделе «Личный кабинет» можно создавать и редактировать профессии и добавлять учебные курсы или собственные названия. «К обучению» открывает выбранный курс. Процент профессии — среднее прохождение её курсов; завершение полного теста курса даёт 100% прохождения независимо от точности ответов. Свои курсы и дополнительные отметки можно отмечать вручную. Знакомые вопросы из открытых опросов не влияют на прогресс профессий и курсов. У ещё не начатых курсов процент не показывается.

Профиль хранится под ключом `answerbook.profile.v1`: в браузере — localStorage, в Android — Capacitor Preferences. Сервер, регистрация и синхронизация между устройствами не используются. Если один курс каталога входит в несколько профессий, его отметка общая для этих профессий. Общий прогресс считает уникальные курсы. Профессии и собственные курсы сохраняются независимо от обновления списка вопросов. При ошибке чтения профиль не перезаписывается пустыми данными.

## Добавление тем в каталог

### Завершение теста и знакомые вопросы

На экране результатов ответы доступны для чтения, редактирования и экспорта. При выходе на главную после завершения теста ответы, номер вопроса и дата завершения очищаются; выбранные темы остаются. Системная кнопка «Назад» на Android с результатов тоже завершает сессию и возвращает на главную. Незавершённый тест можно продолжить, если состав вопросов не изменился.

Перед запуском откройте «Настройки темы» на нужной карточке и поставьте галочки у знакомых вопросов. По умолчанию они исключаются; настройка «Включить вопросы, которые вы уже знаете» возвращает их в тест только для этой темы. Если знакомы все выбранные вопросы, запуск недоступен, пока пользователь не включит знакомые или не снимет отметки. Отметки и настройки тем сохраняются отдельно от сессии под ключом `answerbook.knowledge.v1` (localStorage / Capacitor Preferences). Состав начатого теста фиксируется; конспект содержит только вопросы этого прохождения.

Редактируйте `src/data/questions.json`. Добавьте объект в массив `topics`:

```json
{
  "id": "testing",
  "number": 9,
  "title": "Тестирование",
  "symbol": "✓",
  "color": "green",
  "description": "Качество программ",
  "questions": [
    { "id": "testing-unit", "text": "Что такое модульный тест?" }
  ]
}
```

Используйте уникальные стабильные `id` тем и **глобально уникальные** `id` вопросов: по ним восстанавливаются ответы. Все поля обязательны. Цвета: `violet`, `blue`, `orange`, `green`, `pink`, `teal`. Поле `number` задаёт номер темы. Порядок в JSON определяет порядок опроса и документа.

Текущий каталог: 28 тем, 738 открытых вопросов, `revision: 4`. История расширения: каталог версии 3 содержал 17 тем и 557 вопросов. Все прежние 248 вопросов (включая исходные 162) сохранены с прежними ID, текстом, метаданными и порядком. По обновлённым PDF 01–16 добавлено 309 вопросов для ответа своими словами. Прежние темы языка/OОП, коллекций, памяти, асинхронности, инструментов, алгоритмов и SQL дополнены; PostgreSQL, EF Core, Redis, сети/HTTP/TLS, ASP.NET Core, REST API, безопасность и RabbitMQ выделены в восемь новых тем. Обобщённая прежняя тема HTTP также сохранена. Новые вопросы содержат `block` и `source` с пособием и страницами; варианты и эталонные ответы из учебных курсов не включаются. Задания на вывод кода остаются в курсах.

Версия 4 не позволяет старому кешу или удалённой ленте версии 3 заменить обновлённый встроенный каталог. Начатые опросы используют собственные снимки вопросов; старые отметки знаний сохраняются по ID, а новые вопросы считаются незнакомыми. Прогресс профессий и курсов от отметок знакомых вопросов не зависит. При следующем обновлении увеличивайте `revision`. Контрольные суммы в `tests/fixtures/catalog-v2-fingerprints.json` защищают от случайной потери прежних вопросов.

Реестр `src/data/learning-catalog.json` задаёт порядок курсов, направление, применимость (универсальный / .NET), файлы и страницы исходных пособий. `src/data/learning-directions.json` содержит названия и описания направлений. `src/lib/learningContent.ts` загружает и проверяет все курсы. При добавлении нового курса включите JSON в этот модуль и реестр. `source` и `pages` каждого блока указывают конкретный PDF, в том числе в объединённом курсе по PDF 01 и 02. Все источники и номера страниц проверяются перед сборкой.

Каждый блок содержит три коротких раздела теории и два задания: один из четырёх вариантов или краткий результат кода, SQL, команд либо псевдокода. Для задач с данными и порядком результата условия заданы явно. Объяснения и эталонные ответы показываются в результатах. Пользовательский код не исполняется. SQL-примеры ориентированы на PostgreSQL; универсальность курса относится к принципам, а не идентичности всех диалектов.

В направлении «Web и backend» добавлены сети/HTTP/TLS, ASP.NET Core (курс для .NET), REST API и безопасность. «Обмен сообщениями» включает универсальный курс RabbitMQ с маршрутизацией, confirms/ACK, повторами, outbox/inbox и эксплуатацией. Новые курсы имеют отдельные ключи офлайн-сохранений; версии и ответы первых десяти курсов не изменены.

Обычное прохождение: теория → тест блока → следующая теория. Для перехода из теста нужны ответы на все задания блока. После последнего блока заполненный курс завершается; если раньше были пропуски, открывается полный тест. Две компактные стрелки и общий выпадающий список закреплены под шапкой. Досрочная сдача открывается с карточки курса отдельным экраном. Возврат к обычному обучению сохраняет текущий блок и режим.

Каждый курс сохраняется отдельно: первый продолжает использовать прежний ключ answerbook.learning.csharp.v1, остальные — answerbook.learning.<course-id>.v1. Native Preferences загружаются для всех курсов до старта интерфейса. Курс и его материалы входят в APK и доступны офлайн. Обновление курсов распространяется с новой сборкой; удалённая JSON-лента обновляет каталог открытых вопросов. При обновлении увеличивайте `version` курса. Неизменившиеся вопросы сохраняют ID и порядок вариантов — ответы на них переносятся. Исходное сохранение прежней редакции остаётся в `previousEdition` нового сохранения, включая ответы на перемещённые или удалённые задания. Новые задания требуют отдельного ответа. При изменении смысла вопроса или порядка вариантов обязательно назначайте новый ID; иначе старый ответ будет трактоваться неверно. Старые ключи четырёх курсов сохранены, как и ручные отметки в профессиях. Завершение/повторное начало курса очищает попытку по прежним правилам.

## Профессии и прогресс

В редакторе профессии выбирают учебные курсы AnswerBook, сгруппированные по тем же восьми направлениям. Все 26 курсов доступны для добавления; темы открытого опроса не выбираются. Можно добавлять свои внешние курсы. Ранее выбранные темы сохраняются в прежних профессиях и доступны для удаления в редакторе, чтобы обновление не удаляло пользовательские планы и отметки. Кнопка «К обучению» открывает конкретный выбранный курс.

Список курсов профессии раскрывается нажатием на её название. Процент, число освоенных курсов и полоса прогресса видны всегда. Прогресс профессии учитывает только отметки «Пройден» у её учебных и внешних курсов. Знакомые вопросы открытого опроса не влияют на профессии и учебные курсы. Ранее добавленные темы сохранены для справки и исключены из расчёта прогресса. Учебный тест сам по себе не меняет ручную отметку. Все курсы профессии имеют одинаковый вес, общий прогресс исключает повторные курсы. Проценты округляются до сотых и отображаются с двумя знаками после запятой.

## Мобильная компоновка

Нижнее меню «Каталог / Курсы / Личный кабинет» остаётся на всех экранах. Сводка выбранных тем и начало теста закрепляются под шапкой с отступом 8 px; постоянные дополнительные подписи убраны. «На главную» и «Сохранить» на экране результатов находятся после ответов.

Переменные --mobile-nav-height и --mobile-banner-height в src/mobile.css задают нижнее меню и запас под будущий баннер высотой 112 px. Баннер пока пуст, реклама не подключена. Android SystemBars использует native insets: WebView находится внутри системных панелей, CSS не добавляет safe-area повторно. Шапка имеет высоту 48 px; название выровнено по вертикали.

Проверки контента запускаются перед разработкой и сборкой. npm.cmd test проверяет каталог, офлайн-сохранения, прогресс профессий и последовательное прохождение всех курсов.


## Учебные курсы: теория, проверка и сохранения

В первых 15 курсах расширен 181 блок теории по исходным 16 PDF: главы, ограничения, примеры кода и разборы. Полные разделы находятся в `src/data/learning-readings.json`, сопоставление с уроками и извлечение — в `scripts/extract-learning-readings.py` (нужен Python с pdfplumber; путь к папке PDF можно передать аргументом). Вводные тезисы остаются в JSON курсов. Источники и страницы видны под каждым разделом.

309 заданий с выбором ответа получили предметные отвлекающие варианты. `scripts/upgrade-course-choices.py` содержит их редактируемый список и воспроизводимый порядок вариантов. При изменении значений вариантов нужно менять ID задания и повышать редакцию курса: старый числовой индекс не должен означать новый ответ. `learning-previous-editions.json` хранит предыдущую редакцию для переноса старых результатов; этот файл нельзя перегенерировать из новой редакции.

В обычном режиме после выбора или ввода ответа пользователь нажимает «Проверить ответ». Показываются правильный ответ и объяснение; проверенный ответ фиксируется до нового прохождения. Для следующего блока нужно проверить все ответы текущего. В досрочном тесте проверка доступна только после заполнения всех заданий и сдачи. В результатах ошибки идут первыми, затем правильные ответы.

Сохранение курса включает последний подробный результат (снимок исходных вопросов, ответов, оценки и даты) и последние 20 оценок в истории. Результат доступен после выхода и перезапуска. «Пройти заново» начинает новую попытку, сохраняя предыдущую оценку. «Повторить теорию» открывает чтение без изменения результата. Процент прохождения считается по заполненным заданиям, точность показывается отдельно. Все данные хранятся локально на устройстве.

Серия занятий видна в курсах и личном кабинете. День засчитывается за переход от теории к заданиям, проверку ответа, заполнение ответа в досрочном тесте либо открытом опросе. Открытие страницы само по себе не засчитывается. Используются календарные даты устройства, один день учитывается один раз. После пропущенного дня текущая серия сбрасывается, рекорд сохраняется. Новая история не восстанавливает занятия, которые приложение раньше не фиксировало. Состояние сохраняется отдельно в `answerbook.activity.v1`.


## Работа над ошибками, перемешивание и оформление

На странице результата курса есть «Повторить ошибки». В повторение включаются только неверные ответы из сохранённого снимка результата, включая задания предыдущей редакции. Ответы проверяются отдельной кнопкой и фиксируются. После завершения доступны отдельная оценка, история последних 20 повторений и запуск только оставшихся ошибок. Незавершённая работа сохраняется вместе с курсом; вернуться к ней можно через результат. Исходная оценка, ответы текущего полного прохождения и прогресс профессии не изменяются.

В каждом новом полном прохождении курса и новом повторении ошибок порядок вариантов генерируется заново. В сохранении лежит перестановка исходных индексов, поэтому проверка и выбранный ответ не зависят от позиции на экране. При продолжении незавершённой попытки порядок остаётся стабильным. В темах открытого опроса вопросы перемешиваются внутри каждой темы при новом запуске, сохраняются в questionIds и продолжаются в том же порядке после перезапуска. Новый завершённый опрос не повторяет предыдущую последовательность темы, если вопросов больше одного.

Кнопка солнца/луны в верхней панели переключает светлое и тёмное оформление на всех экранах. По умолчанию используется светлая тема; выбор сохраняется в `answerbook.theme.v1` отдельно от профиля. Палитры — переменные в `src/theme.css`, общий макет сохраняется. Печать использует светлую палитру. Android WebView не выполняет стандартное принудительное затемнение, системные панели согласуются с выбранной темой через локальный плагин Appearance. Настройки безопасности и системная тема телефона не изменяются.


## Полная библиотека пособий 01–27

В версии 1.25 добавлены 11 курсов и 11 тем каталога по PDF 17–27:

- Тестирование и качество: теория тестирования и тест-дизайн; автотесты .NET/xUnit; производительность и нагрузочное тестирование.
- Инструменты и эксплуатация: Git; Linux; Docker/Compose; CI/CD; наблюдаемость.
- Архитектура и надёжность: архитектура/SOLID/паттерны; распределённые системы/микросервисы; System Design/надёжность.

Новые 96 блоков содержат 192 задания (181 с выбором ответа и 11 коротких разборов/расчётов) и полные соответствующие разделы источников, включая буквенные главы 20А–20Е и 23А–23Е. В открытом каталоге появились 181 вопрос. Всего: 26 курсов, 8 направлений, 277 блоков, 554 учебных задания, 28 тем и 738 открытых вопросов. Все курсы доступны в редакторе профессии.

Содержимое заданий и группировка новых глав описаны в `scripts/add-remaining-courses.py`. Источники, страницы и группы `readingChapters` хранятся в JSON каждого курса. `scripts/extract-learning-readings.py` воспроизводит библиотеку чтения по исходным PDF. При новом курсе без предыдущей редакции `previous` не требуется. JSON-файлы `*-course.json` подключаются автоматически через Vite; добавить запись в каталог курсов и соответствующие источники всё равно необходимо. Старые 15 редакций и 557 вопросов защищены регрессионными отпечатками. Версия открытого каталога повышена до 4, поэтому сохранённый каталог версии 3 не заменит новую встроенную библиотеку.
