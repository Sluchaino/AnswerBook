## Запуск сайта

```powershell
npm.cmd install
npm.cmd run dev
```

Node.js находится в C:\MyApps\Nodejs. Если PATH не настроен, добавьте этот каталог или используйте полный путь к npm.cmd.

## Сервер

```powershell
npm.cmd run content:publish
npm.cmd run server:dev
```

Для локальной разработки Vite проксирует /api на порт 5129. Новые сборки сайта и Android используют каталог Yandex Object Storage `answerbook-content-2026`. Подробнее: [сервер контента](docs/content-server.md) и [выборочная библиотека](docs/course-library.md).

Скачанные удалённые курсы очищаются в обновлённом клиенте, даже без сети. Перечень удалённых ID нужен для миграции и не содержит теории или заданий. Удаление курсов не очищает личные ответы на открытые вопросы.

## Android

npm.cmd run android:apk собирает APK в artifacts/. Шрифты, открытые вопросы и лёгкий каталог курсов встроены в приложение. Теория, тесты и интерактивы курсов загружаются по кнопке «Скачать», обновляются по «Обновить» и удаляются по «Удалить». Материалы после скачивания работают офлайн. Адрес хранилища задан в src/data/content-host.json; VITE_COURSES_URL позволяет его переопределить. Авторские исходники курсов сохраняются в проекте, но не входят в APK.

Классический дизайн сохранён в [design-history/classic-1.25](design-history/classic-1.25/README.md) без учебных материалов. Учебные данные из архива удалены, визуальные стили сохранены без изменений.

Интерактивные упражнения (этап 1): [сопоставление и последовательность, добавление через JSON](docs/interactive-exercises.md). Примеры встроены в уроки о системе типов и try/catch/finally; они сохраняются офлайн и не влияют на оценку.

Интерактивы, этап 2: добавлена сборка кода `code-order` с предпросмотром и тремя упражнениями (for, try/catch/finally, async/await). Формат и добавление — в [документации](docs/interactive-exercises.md).

Интерактивы, этап 3: `code-debug` — выбор ошибочной строки и исправления, предпросмотр, разбор, повторение и офлайн-сохранения. Три примера добавлены в уроки GetHashCode, throw и async/await. Формат — в [документации](docs/interactive-exercises.md).

Интерактивы, этап 4: `data-transform` — Filter, Select, OrderBy/ThenBy, GroupBy и Count с промежуточными данными, редактированием цепочки и проверкой результата/условий. Три примера добавлены в коллекции и LINQ; [формат и ограничения](docs/interactive-exercises.md).


### Локальный визуальный редактор упражнений

Запустите `npm run authoring:dev` и обычный `npm run dev -- --host 127.0.0.1 --port 5193 --strictPort`, затем откройте `http://127.0.0.1:5193/#/authoring`. Ключ управления находится в `.tools/authoring-token.txt`; он создаётся при первом запуске и не публикуется. Сервер разрешает редактор только в Development, с loopback и верным ключом. В Production административные операции отключены.

Редактор поддерживает семь типов, изолированный предпросмотр, черновики на диске, размещение, явную публикацию, импорт и экспорт. Опубликованные упражнения записываются в прежний sidecar, поэтому Markdown-импорт не затирает изменения редактора. Подробности — [документация редактора](docs/exercise-editor.md).
