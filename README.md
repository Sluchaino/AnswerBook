# AnswerBook

Выбор тем, письменные ответы и личный конспект. Без бэкенда и аккаунтов.

## Запуск

В новом PowerShell (Node.js 24 и npm):

```powershell
cd C:\MyApps\MyProjects\BackendAnswerBook
npm.cmd install
npm.cmd run dev
```

Откройте напечатанный Vite адрес. Если PATH не обновился, используйте `C:\MyApps\Nodejs\npm.cmd` вместо `npm.cmd`.

## Возможности

- Выбор одной или нескольких тем, выбор всех тем.
- Навигация между вопросами, свободный текст, пропуск вопросов.
- Сохранение тем, ответов и позиции в localStorage.
- Документ по темам, редактирование ответов, новый опрос с подтверждением удаления.
- Копирование текста, скачивание UTF-8 `.txt`, PDF через диалог печати. Выберите «Сохранить как PDF»; при необходимости отключите колонтитулы браузера.
- Мобильный интерфейс и отдельное оформление для печати.

Данные остаются в текущем браузере на текущем адресе сайта. Очистка данных браузера удаляет прогресс. Смена домена создаёт отдельное хранилище. Важные ответы нужно выгружать. Если localStorage недоступен, приложение показывает предупреждение, но позволяет отвечать и экспортировать.

## Добавление вопросов

Редактируйте `src/data/questions.json`. Добавьте объект в массив `topics`:

```json
{
  "id": "testing",
  "number": 9,
  "title": "Тестирование",
  "symbol": "✓",
  "color": "green",
  "description": "Качество программ",
  "questions": [
    { "id": "testing-unit", "text": "Что такое модульный тест?" }
  ]
}
```

Используйте уникальные стабильные `id` тем и **глобально уникальные** `id` вопросов: по ним восстанавливаются ответы. Все поля обязательны. Цвета: `violet`, `blue`, `orange`, `green`, `pink`, `teal`. Поле `number` задаёт номер темы. Порядок в JSON определяет порядок опроса и документа.

Текущий список перенесён из предоставленного текста: 8 тем, 162 вопроса. Формулировки и порядок сохранены. Темы отображаются единым списком.

После изменения JSON сайт нужно пересобрать и опубликовать. Ответы на удалённые вопросы не попадут в новый документ. При изменении смысла вопроса назначьте новый `id`, чтобы не привязать старый ответ к новому вопросу.

При запуске и сборке автоматически проверяются обязательные поля, цвета, наличие вопросов и уникальность идентификаторов. Ошибки в JSON нужно исправить до публикации.

## Сборка и публикация

```powershell
npm.cmd run build
npm.cmd run preview
```

Для статического хостинга: команда сборки `npm run build`, каталог публикации `dist`, Node.js 24. Все экраны работают на одном URL, перенаправления SPA не нужны. Golos Text загружается из Google Fonts; при недоступности используется системный шрифт.
