# AnswerBook — классический дизайн 1.25

Снимок исходников перед обновлением дизайна: 23 октября 2026 года.
Зелёная палитра, светлый фон с тёплым оттенком, заголовки с курсивом, исходные карточки, навигация, светлая и тёмная темы сохранены в архиве.

Архив содержит весь src (включая учебные материалы), конфигурацию сборки и нативные исходники оформления Android. manifest.json хранит SHA-256 каждого файла; содержимое архива проверено после создания.

Для возврата к этому оформлению распакуйте архив в ОТДЕЛЬНУЮ папку и используйте его как эталон. При переносе оформления в текущий проект сравните стили, JSX, theme.ts и нативные цвета; не заменяйте учебные данные и логику более новой версии целиком. Архив не содержит пользовательских данных, node_modules, Android SDK или ключей подписи.

Готовая предыдущая сборка: artifacts/AnswerBook-1.25-mobile.apk в корне проекта. Для повторной Android-сборки используйте существующий Android-проект и сохранённый ключ подписи.
