# ASP.NET Core — Привязка данных и HTTP-результаты

Четвёртый модуль нового курса добавлен по девяти файлам уроков, контрольному тесту и ключу. Оригиналы находятся в `server/theory-source/aspnet-core-v2-module04/`. Курс `aspnet-core-foundations-v2` v24, каталог revision 205.

Девять уроков содержат 18 мини-проверок, 45 итоговых вопросов и 20 вопросов контрольного теста — всего 83 с пояснениями. Пять интерактивов размещены в разных уроках: источники Route/Query (2), результаты JSON-binding (4), исправление проверки DisplayName (6), настройки JSON-контракта (8), сборка ответа с метаданными до тела (9). При сборке принимаются оба порядка установки статуса и заголовков. Дополнительные уроки не создавались.

В программе доступны четыре модуля из 27: 33 урока, 20 интерактивов, 66 мини-проверок и 245 вопросов на оценку. Модули 5–27 показывают «Скоро появится». Первые три модуля, их вопросы, ID и размещения упражнений сохранены; C# и его sidecar сверены по SHA-256. Для загруженных уроков программа использует фактические заголовки файлов вместо предварительных формулировок плана; ID и будущие уроки не меняются. Ключи, источники и служебные заметки не выводятся в ученической теории.

## Проверки

- 390 автоматических тестов, семь API-проверок, успешная веб-сборка. Lint содержит восемь прежних предупреждений.
- `scripts/check-aspnet-v2-module04.mjs`: 32 успешных SDK/HTTP-сценария, включая все 26 полных Program.cs, два порядка сборки ручного ответа и четыре варианта проверки профиля. Проверены Route/Query/Header/Cookie, имена атрибутов, binding 400 против route 404, JSON 400/415, текст и JSON Content-Type, Set-Cookie, Location, 201/202/204, union TypedResults, JsonIgnore/JsonPropertyName, null/indent, Cache-Control/ETag и redirect 301 без автоматического следования. Учебные примеры не изменялись; проверочный harness использует локальный случайный порт.
- На ширине 390 px проверены доступность 4/27 и пять интерактивов: неверное/правильное решение, восстановление после перезагрузки и сброс. Консоль без ошибок, горизонтального переполнения нет. Отчёт: `artifacts/aspnet-v2-module04-ui-results.json`.
- Повторный импорт и публикация сохраняют v24 без дубликатов. Серверный каталог и резервная публикация revision 205 совпадают; payload сверены по SHA-256.

Результаты SDK: `artifacts/aspnet-v2-module04-sdk/results.json`. APK не пересобирался. SDK выполняет только фиксированные учебные примеры; пользовательский код в приложении не запускается.
