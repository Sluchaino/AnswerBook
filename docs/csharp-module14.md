# Курс C#: модуль 14 — Исключения и управление ресурсами

Восемь уроков: распространение исключений, try/catch/finally, throw и повторное выбрасывание, пользовательские исключения, фильтры when, IDisposable и using, Dispose Pattern, IAsyncDisposable и await using.

Добавлены 16 тренировочных вопросов, 40 итоговых вопросов уроков и 20 контрольных. Все задания с одним правильным ответом. Курс версии 14 содержит 14 модулей, 123 урока, 246 тренировочных и 895 оцениваемых вопросов.

Оригиналы сохранены в server/theory-source/csharp-module14. Импорт сверяет текстовые ответы с JSON-массивом ключей, поддерживает локальные обозначения М1/И1/К1. Служебные файлы не отображаются как уроки; примеры и заключительные рекомендации сохранены. Объяснения раскрываются по правилам проверки, прохождение доступно офлайн.

Первые 13 модулей не изменены. Проверены перенос ответов, результатов, первой и лучшей попыток, а также переход от экзамена модуля 13 к теории модуля 14. Прогресс пересчитывается с учётом нового материала.

Импорт: npm.cmd run content:import:csharp. Проверки: npm.cmd test, npm.cmd run build, npm.cmd run lint. Публикация: npm.cmd run content:publish. Повторный импорт не меняет версию без изменения содержимого.

APK 1.39 содержит первые восемь модулей. Для новых материалов требуется новая сборка либо загрузка в клиенте с настроенным сервером. APK в этой итерации не пересобирался.
