# ASP.NET Core — Разработка Minimal APIs

Седьмой модуль добавлен по девяти файлам уроков, контрольному тесту и ключу. Оригиналы без изменения находятся в `server/theory-source/aspnet-core-v2-module07/`. Курс `aspnet-core-foundations-v2` v45, каталог revision 223.

Девять уроков содержат 18 мини-проверок, 45 итоговых вопросов уроков и 20 контрольных — всего 83 с пояснениями. Пять интерактивов размещены по одному в уроках 2, 4, 5, 6 и 8: CRUD-цикл, сборка union-результата, порядок endpoint filters, включение валидации .NET 10 и контракт файловых операций. Дополнительные уроки не создавались.

Теперь доступны семь модулей из 27: 62 урока, 35 интерактивов, 124 мини-проверки и 450 вопросов на оценку. Модули 8–27 показывают «Скоро появится». Первые шесть модулей и их размещения упражнений сохранены; C# и его sidecar сверены по SHA-256. Ключи, авторские заметки и источники не выводятся в ученической теории.

## Проверки

- 402 автоматических теста и семь API-проверок проходят. Веб-сборка успешна, lint содержит восемь прежних предупреждений.
- `scripts/check-aspnet-v2-module07.mjs`: 23 успешных SDK/HTTP-сценария с Microsoft.Extensions.Validation и Microsoft.AspNetCore.OpenApi 10.0.14. Проверены 12 Program.cs с необходимыми типами из соседних блоков, полный CRUD с PUT/DELETE, AsParameters, фильтр положительного Id с проверкой short-circuit, IValidatableObject, union/OpenAPI, загрузка/скачивание, эталон сборки и четыре варианта регистрации валидации.
- Фрагменты с зависимыми классами собираются в проверочном проекте с соответствующими типами. SearchArguments используется в отдельном helper-методе; feature endpoints и NoteStore — в отдельном файле. Исходные фрагменты не выдаются за самостоятельные Program.cs и не изменялись.
- Проверены некорректные email/возраст, успешный 201, 200/404 ветки union, документ /openapi/v1.json, точный порядок A/B фильтров. Файлы проверяются через multipart, ограничения пустого/большого содержимого, корректный download и невалидный/отсутствующий Id. TEMP/TMP тестового процесса направлены в `artifacts/aspnet-v2-module07-sdk/uploads`; пользовательский каталог Temp не используется для загружаемых данных.
- На ширине 390 px подтверждены 7/27 и пять интерактивов с неверным/правильным решением, восстановлением после перезагрузки и сбросом. Консоль без ошибок, горизонтального переполнения нет.
- Повторный импорт и публикация сохраняют v45 без дубликатов. Серверный и резервный каталоги revision 223 совпадают; payload проверены по SHA-256.

Отчёты: `artifacts/aspnet-v2-module07-sdk/results.json`, `artifacts/aspnet-v2-module07-ui-results.json`. APK не пересобирался. Пользовательский код в приложении не выполняется. DisableAntiforgery в материале остаётся явно ограниченным учебным небраузерным сценарием.
