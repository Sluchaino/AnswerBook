# ASP.NET Core — Controller-based Web API

Восьмой модуль добавлен по девяти файлам уроков, контрольному тесту и ключу. Неизменённые оригиналы находятся в `server/theory-source/aspnet-core-v2-module08/`. Курс `aspnet-core-foundations-v2` v53, каталог revision 229.

Девять уроков содержат 18 мини-проверок, 45 итоговых вопросов уроков и 20 контрольных — всего 83 с пояснениями. Пять интерактивов размещены по одному в уроках 3, 4, 6, 7 и 8: маршруты actions, исправление автоматического 400, сборка ActionResult, согласование формата ответа и границы MVC-фильтров. Дополнительные уроки не создавались.

Доступны восемь модулей из 27: 71 урок, 40 интерактивов, 142 мини-проверки и 515 вопросов на оценку. Модули 9–27 показывают «Скоро появится». Первые семь модулей и их упражнения сохранены, курс C# и его sidecar сверены по SHA-256. Источники и ключи не отображаются в ученической теории.

## Исправления учебных примеров

В исходных DTO positional records атрибуты проверки назначались свойствам через `property:`. MVC использует метаданные параметров конструктора; такая комбинация приводила к 500. При импорте этого модуля назначение изменено на `param:`, включая интерактив автоматического 400 (v2). Для decimal Price используется Range с typeof(decimal) и инвариантными границами, чтобы дробные значения меньше единицы отклонялись без округления к int. Исходные Markdown не менялись.
