# Очистка устаревших материалов курсов

По запросу пользователя удалены 38 устаревших файлов и папок, всего 176 файлов (93 669 908 байт):

- Go-course-plan и Go-course-authoring-kit, их ZIP-архивы, специальный скрипт подготовки комплекта Go и связанный промпт.
- Анализ и промпт завершения удалённого Python-курса, старый снимок его первого модуля.
- Прежние резервные снимки модулей ASP.NET Core и партий интерактивов C#, промежуточный JSON до исправления примеров ASP.NET Core, удалённый практический урок ASP.NET Core и payload ранее удалённых курсов.
- Устаревший архив исходников revision 268.
- Пакеты облачной загрузки revision 261, 263, 268, 269, 270 из artifacts/s3-upload и course-library/upload.

Сохранены действующие исходники C#, ASP.NET Core и SQL в server/*-source, их полные копии course-library/sources, последний комплект revision 271 и ZIP для загрузки. Не удалялись ключи подписи, APK, инструменты сборки, фикстуры тестов и исторические отчёты проверок действующих курсов. Исторические отчёты могут упоминать прежние резервные папки, удалённые при этой очистке.

Все цели перед рекурсивным удалением разрешены в абсолютные пути внутри рабочей папки и проверены на пересечение с защищёнными папками. После очистки сверены SHA-256 всех 1 726 защищённых файлов: пропусков или изменений нет.

Валидация текущего контента успешна: 29 тем, 685 открытых вопросов, 3 курса. Десять проверок архивирования библиотеки и загрузки курсов прошли без ошибок. В активных исходниках, скриптах, README и тестах не осталось ссылок на удалённые Go-комплекты.

Локальные журналы, исключённые из Git:

- artifacts/obsolete-course-cleanup-plan.json — точный список удалённых целей и размеров;
- artifacts/obsolete-course-protected-files.json — контрольные суммы сохранённых файлов;
- artifacts/obsolete-course-cleanup-result.json — результат удаления;
- artifacts/obsolete-course-cleanup-tests.log — результаты проверок.
