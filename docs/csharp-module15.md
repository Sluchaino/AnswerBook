# Курс C#: модуль 15 — Тестирование на C#

Добавлены 12 уроков: основы тестирования, тестовые фреймворки и проект, AAA и Fact, Theory и данные, Assert и исключения, границы и качество, test doubles, NSubstitute, изоляция окружения, асинхронные тесты, покрытие, TDD.

В модуле 24 тренировочных вопроса, 60 итоговых вопросов уроков и 20 вопросов контрольного теста. Все задания с одним правильным ответом. Курс версии 15 содержит 15 модулей, 135 уроков, 270 тренировочных и 975 оцениваемых вопросов.

Оригиналы Markdown сохранены в server/theory-source/csharp-module15. Импортёр сверяет текстовые ответы с JSON-ключами в объектах mini/final/exam. Служебные файлы не отображаются как уроки; все примеры кода и заключительные рекомендации сохранены. Объяснения раскрываются по правилам соответствующего теста; проверка работает офлайн.

Первые 14 модулей не изменены. Проверены перенос ответов, результатов, первой и лучшей попыток и переход от экзамена модуля 14 к теории модуля 15. Прогресс пересчитывается с учётом нового материала.

Импорт: npm.cmd run content:import:csharp. Проверки: npm.cmd test, npm.cmd run build, npm.cmd run lint. Публикация: npm.cmd run content:publish. Повторный импорт не меняет версию без изменения содержимого.

APK 1.39 содержит первые восемь модулей. Для новых материалов требуется новая сборка либо загрузка в клиенте с настроенным сервером. APK в этой итерации не пересобирался.
