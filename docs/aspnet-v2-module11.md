# ASP.NET Core — Основы EF Core и моделирование данных

Одиннадцатый модуль добавлен по десяти файлам уроков, контрольному тесту и ключу. Оригиналы без изменений находятся в `server/theory-source/aspnet-core-v2-module11/`. Курс `aspnet-core-foundations-v2` v72, каталог revision 245.

Десять уроков содержат 20 мини-проверок, 50 итоговых вопросов уроков и 20 контрольных — всего 90 с пояснениями. Пять интерактивов размещены по одному в уроках 2, 6, 7, 8 и 10: жизненный цикл DbContext, сборка one-to-many с Restrict, join-модель, исправление уникальности индекса и подготовка миграций. Дополнительные уроки не создавались.

Доступны одиннадцать модулей из 27: 100 уроков, 55 интерактивов, 200 мини-проверок и 720 вопросов на оценку. Модули 12–27 показывают «Скоро появится». Первые десять модулей и их размещения упражнений сохранены; курс C# и его sidecar сверены по SHA-256. Ключи и источники не показываются в ученической теории. Code fences сохранены без исправлений.

## Проверки

- 418 автоматических тестов и семь API-проверок проходят. Веб-сборка успешна. Lint содержит восемь прежних предупреждений; сборщик предупреждает о размере основного JS-файла.
- `scripts/check-aspnet-v2-module11.mjs`: 11 успешных сценариев EF-модели/SQL на .NET 10 с Npgsql.EntityFrameworkCore.PostgreSQL 10.0.3. Проверяются архитектурная модель, состояние Added до записи, DI-регистрация Npgsql, Fluent API, precision/length, обязательный FK с Restrict, one-to-one, skip join и явная join-сущность, complex property, default SQL, check constraints и генерируемый DDL.
- Примеры объединяются с явно необходимыми типами и конфигурациями из соседних уроков. Альтернативная явная join-модель проверяется отдельно от skip navigations. EF DesignTimeModel используется для проверки метаданных ограничений.
- Из фрагментов миграции собран класс Migration; проверены AddColumn/DropColumn, генерация SQL и RenameColumnOperation. Команды установки dotnet-ef, database update, migration bundle и миграции в PostgreSQL не запускались. Реального подключения, применения DDL и проверки ограничений под конкурентной записью не было. Generated SQL не выдаётся за проверку применённой схемы.
- Обе задачи с кодом компилируются. Для связи проверяются требуемый FK и Restrict; для всех четырёх исправлений индекса проверяется IsUnique. Имя UX и направление сортировки сами по себе не задают уникальность.
- На ширине 390 px проверены правильные/неправильные решения всех пяти заданий, восстановление после перезагрузки и сброс рабочего ответа. Сброс сохраняет ранее полученную отметку успешного выполнения. Консоль без ошибок, горизонтального переполнения нет.
- Повторный импорт и публикация идемпотентны. Основной и резервный каталоги revision 245 совпадают; payload проверены по SHA-256.

Отчёты: `artifacts/aspnet-v2-module11-sdk/results.json`, `artifacts/aspnet-v2-module11-ui-results.json`. APK не пересобирался. Пользовательский код в приложении не выполняется.
