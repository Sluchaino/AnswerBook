# Курс C#: модуль 9 — Объекты, ссылки и равенство

Добавлен девятый модуль курса csharp-foundations-v2. Версия содержимого — 9. Всего: 9 модулей, 77 уроков, 154 обучающих мини-проверки и 565 оцениваемых вопросов (719 заданий с учётом тренировок).

Новый модуль содержит 9 уроков, 18 мини-проверок, 45 итоговых вопросов уроков и контрольный тест на 20 вопросов. Всего 83 задания, из них 10 с несколькими правильными вариантами.

1. Копирование значений, ссылок и объектов.
2. Upcasting, downcasting и безопасное преобразование.
3. Boxing и unboxing значимых типов.
4. Операторы ==, Equals и ReferenceEquals.
5. GetHashCode: контракт равенства и хеширование.
6. IEquatable<T> и сравнение в обобщённых коллекциях.
7. Nullable value types: Nullable<T>, HasValue, Value.
8. Nullable reference types и анализ null.
9. Оператор !, защита от null и границы доверия.

12 исходных файлов, включая полученный отдельно README, сохранены в server/theory-source/csharp-module09. Все кодовые примеры сохранены. Локальные номера заданий привязаны к уроку и преобразованы в стабильные ID M09-L01-P1, M09-L09-F5, M09-EX-20. Все ответы сверены с соответствующим разделом ключа. README и ключ не отображаются отдельными учебными страницами.

Первые восемь модулей не изменились. Ответы, результаты, первая и лучшая попытки переносятся. Курс сохраняет прежний ID: повторная покупка не нужна. Общий прогресс учитывает новые вопросы; награда за тот же курс повторно не выдаётся. После контрольного теста модуля 8 открывается теория модуля 9.

Мини-проверки не входят в точность, итоговые тесты отправляются целиком. Множественный выбор засчитывается только за точный набор. Закреплённая строка стрелок и дизайн не менялись.

Импорт: npm.cmd run content:import:csharp. Проверки: npm.cmd test, npm.cmd run build. Публикация: npm.cmd run content:publish. Повторный импорт без изменений не повышает версию.
