# Курс C#: модуль 2 — Типы данных и переменные

В существующий курс `csharp-foundations-v2` добавлен второй модуль. На момент добавления модуль 2 довёл курс до 16 уроков и 120 оцениваемых вопросов. Сейчас добавлен [модуль 3](csharp-module03.md): всего 24 урока и 180 оцениваемых вопросов. Версия содержимого повышена с 1 до 2, ID курса не изменён: повторно покупать его не нужно.

Состав нового модуля: 9 уроков, 18 мини-проверок, 45 итоговых вопросов уроков и контрольный тест на 20 вопросов. Из 83 новых заданий 11 допускают несколько правильных вариантов.

Уроки:

1. Система типов C#.
2. Значимые и ссылочные типы.
3. Целочисленные типы и литералы.
4. Вещественные числа: float, double и decimal.
5. Типы bool, char, string и object.
6. Переменные, var, default и область видимости.
7. Преобразования типов и разбор пользовательского ввода.
8. Переполнение: checked и unchecked.
9. dynamic и статическая типизация.

Теория, таблицы и примеры кода сохранены из предоставленных материалов. Мини-проверки не влияют на точность; итоговые и контрольные тесты отправляются целиком. Ответы и объяснения сверены с отдельным ключом. Рекомендуемый порог контрольного теста — 80%, повторные попытки доступны.

Первый модуль сохранён без изменений, включая все ID уроков и заданий. Его ответы, первая/лучшая попытки и сохранённый результат остаются доступны. При добавлении нового модуля общий процент пересчитывается с учётом новых заданий; старый результат остаётся результатом предыдущей редакции. За один и тот же курс повторная награда не выдаётся.

После контрольного теста первого модуля стрелка вперёд ведёт к теории второго. В кастомном списке модулей доступны оба модуля; контрольный тест второго находится в его списке уроков.

## Импорт и публикация

12 исходных Markdown-файлов находятся в `server/theory-source/csharp-module02`. Импортёр `scripts/import-csharp-course.mjs` теперь собирает три модуля через общую функцию `scripts/lib/import-markdown-module.mjs`:

```powershell
npm.cmd run content:import:csharp
npm.cmd test
npm.cmd run build
npm.cmd run content:publish
```

Повторный импорт тех же материалов сохраняет номер версии. При изменении содержимого существующего курса версия автоматически повышается. Первый аргумент скрипта — общий каталог исходников с подпапками `csharp-module01`, `csharp-module02`, `csharp-module03`.

README и ключ не показываются как учебные страницы. Ключ используется для создания статических ответов и объяснений, необходимых для офлайн-проверки. Добавлен модуль 3. На момент этой редакции были добавлены первые три модуля.

Текущее состояние: добавлен [модуль 4](csharp-module04.md). В APK 1.37 включены 4 модуля, 32 урока и 240 оцениваемых вопросов. Добавлен [модуль 5](csharp-module05.md); текущий курс содержит 41 урок и 305 оцениваемых вопросов. Модули 6–19 пока не добавлены.
