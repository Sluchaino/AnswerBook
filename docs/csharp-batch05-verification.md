# Минимум пять интерактивов на модуль, максимум один на урок

27 октября 2026 года. По уточнению пользователя применяется **минимум пять на модуль и не больше одного в уроке**. Не требуется заполнять каждый из 177 уроков.

Было **62**, добавлено **34**, стало **96**. У 18 модулей по **5**, у управляющих конструкций — **6**. В 96 уроках по одному интерактиву, в 81 пока нет. Курс **v70 → v114**, каталог **revision 79 → 123**.

[Полная таблица всех 19 модулей, 34 новых заданий, 10 переносов и 96 опубликованных упражнений](csharp-interactive-coverage.md).

## Публикация и импорт

`scripts/publish-csharp-batch05.mjs` предварительно проверяет весь будущий курс: 34 новых, десять разрешённых переносов, 96 уникальных ID, существование якорей, минимум пять на модуль, максимум один на урок. Для переноса используется штатное save/publish существующего упражнения с прежним fingerprint; для новых — импорт черновиков и явная публикация через тот же защищённый authoring API.

Ключ читается из игнорируемого файла, не печатается и не включается в клиент. Публикация повысила версию курса 44 раза — по одному на десять переносов и 34 новых блока. Версии самих старых упражнений не изменились. Повторный запуск подтвердил Already moved/Already published без новой версии.

Два `npm run content:import:csharp` сохранили **v114**, все 96 заданий и размещения. Копия контента `artifacts/content-server/content` опубликована штатным издателем с revision 123; SHA-256, размер payload и каталог сверены с основным серверным каталогом.

## Сохранения и текущая позиция

Перенос не меняет fingerprint упражнения, поэтому его ответ, история проверок и успешное решение остаются совместимыми. Исправлен выявленный крайний случай в `restoreLearningAttempt`: если прежний ID шага исчез только из-за переноса, позиция теперь находится по тому же валидированному упражнению. При наличии прежнего курса учитывается стабильный ID упражнения; без него — уникальный сохранённый ID блока и валидное состояние. При неизвестных или неоднозначных данных остаётся обычный безопасный fallback.

Проверены все десять переносов с начальным и решённым состояниями, с прежней редакцией и без неё. Отдельно восстановлено полностью сданное сохранение v70 со всеми **62** выполненными интерактивами, всеми ответами и оценкой **100%**: ответы, упражнения, результаты проверок, итоговая оценка и завершённость сохранены.

Обычная теория, **177 уроков**, **354** мини-проверки и **1265** оцениваемых вопросов совпадают по хешам. Порядок исходных модулей и отдельный порядок интерфейса не менялись: m01 остаётся последним на экране. Исторические тесты предыдущих партий воспроизводят полные старые размещения из снимков; новая проверка сравнивает каждый старый блок с живым текущим курсом. Для исторического v70 payload воспроизводится стандартным сериализатором и сверяется с сохранёнными SHA-256/bytes, без зависимости от оставшегося старого генерируемого файла.

## .NET SDK

Команда: `node --experimental-strip-types scripts/check-csharp-batch05.mjs`; при подготовке передавался `--source artifacts/csharp-batch05-candidates.json`. Ожидания фиксированных сценариев: `tests/fixtures/csharp-batch05-sdk-cases.json`. Содержимое опубликованных упражнений сверено с проверенными кандидатами; API нормализует только внешние ID новых блоков до ID упражнений.

**124/124** сценария прошли: .NET SDK **10.0.400**, C# **14**, **net10.0**. Проверены все предлагаемые исправления, включая допустимые альтернативы и неверные варианты, ожидаемые ошибки компиляции и выполнения, вывод программ и все три собираемые программы. Строковые сравнения вывода учитывают значимые пробелы и используют инвариантную культуру там, где результат зависит от форматирования дроби.

Проверки также включают дополнительные сценарии: совместимый Dog сохраняет успешное преобразование, непустой обязательный аргумент корректен, неотменённый токен разрешает завершение, неудачный CompareExchange не считается успешным. Для abstract, composition, типов делегатов и чтения атрибута выполнены отдельные фиксированные программы. Намеренные deadlock/зависания не запускаются.

Настоящие пакеты xUnit **2.9.3**, Test SDK **17.14.1**, runner **3.1.4** подтвердили два Passed для Theory/InlineData, обнаружили неправильный Fact с параметрами, пропуск и намеренно ошибочную реализацию проверки чётности. Ошибочные примеры являются ожидаемыми отрицательными проверками.

Во время подготовки SDK выявил недопустимое контекстное имя `group` в query syntax одного кандидата SelectMany. До публикации имя изменено на `batch`, после чего оба правильных варианта скомпилированы и выполнены. Опубликованного неверного варианта не было.

Результаты: `artifacts/csharp-batch05-sdk/results.json`, `artifacts/csharp-batch05-sdk-log.txt`. Исполнение остаётся инструментом подготовки разработчика: приложение и Content API не исполняют пользовательский код.

## Ограничения

Задания не добавлены во все 177 уроков: применяется выбранный минимум пяти на модуль. Эталоны доступны офлайн, это учебная проверка. Трассировки остаются готовыми сценариями, не отладчиком. Старые простые демо сохранены целиком; прежняя редакционная оговорка m05 о текстовом порядке объявления метода не переписывалась в этой задаче.

**APK не пересобирался.** Последняя отдельная сборка — 1.42 с прежним встроенным контентом. Для включения 96 заданий и обновлённого восстановления позиции в офлайн-сборку потребуется следующая APK. Другие функции и новые механики не добавлялись.
