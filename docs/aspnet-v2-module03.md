# ASP.NET Core — Маршрутизация и Endpoint Routing

Третий модуль добавлен по девяти файлам уроков, контрольному тесту и ключу. Исходные файлы сохранены без изменения в `server/theory-source/aspnet-core-v2-module03/`. Курс `aspnet-core-foundations-v2` v18, каталог revision 200.

Девять уроков содержат 18 мини-проверок, 45 итоговых вопросов уроков и 20 контрольных вопросов с пояснениями — всего 83. Пять интерактивов размещены по одному в уроках 3, 5, 6, 7 и 9: выбор endpoint по constraints, catch-all при сопоставлении/генерации URL, исправление неоднозначности, сборка MapGroup, диагностика HTTP/сетевых результатов. Для группы принимаются оба порядка независимых GET/POST. Дополнительные уроки не создавались.

Теперь доступны три модуля из 27, 24 урока, 15 интерактивов, 48 мини-проверок и 180 вопросов на оценку. Модули 4–27 показывают «Скоро появится». Первые два модуля и их размещения упражнений сохранены по байтам структуры; C# и его упражнения сверены по SHA-256.

## Сохранение литералов

Импорт этого модуля использует `preserveLiteralStars`: код внутри обратных кавычек защищается от удаления Markdown-выделения, а непарные двойные звёздочки остаются текстом. Это сохраняет `{**path}` в теории и `/reports/{**year:int}` среди неверных вариантов контрольного вопроса. Прежний режим импорта других курсов сохранён. Ключи ответов, служебные заметки и источники не выводятся в ученической теории.
