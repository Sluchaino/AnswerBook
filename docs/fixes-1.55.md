# Исправления после проверки 1.54

## Хранение

Полное удаление сначала фиксирует в библиотеке удаление материалов/сводки и pendingPurges. До успешной записи этой операции ответы и ручные отметки не меняются. Очистка попытки и профиля идемпотентна; прерванная очистка завершается до открытия приложения или следующей операции с библиотекой. Журнал снимается после очистки. Ошибка второго этапа сообщает пользователю о сохранённом намерении удаления и необходимости повтора/перезапуска.

Браузерные операции сериализуются через Web Locks между вкладками и читают последний устойчивый снимок под блокировкой. Дополнительно IndexedDB транзакция проверяет исходный снимок перед заменой, предотвращая тихую перезапись при конфликте, в том числе без Web Locks. Профиль интерфейса обновляется из сохранённого состояния и при ошибке удаления.

В Android недоступность localStorage не блокирует удаление из Preferences; при загрузке Preferences остаётся источником истины для попыток, включая отсутствующие значения.

## Интерфейс и Android

- Успешный callback загрузки баннера восстанавливает VISIBLE.
- Генерируемые варианты code-debug исключают визуальные повторы, сохраняя ID оставшихся вариантов. Отрисовка использует полный набор оставшихся вариантов независимо от количества авторских исправлений. Пояснения к коду не возвращались.
- Название конспекта и префикс TXT заменены на КодШаг/kodshag.

## Проверка

- 527 автоматических тестов прошли, включая журнал удаления и уникальность вариантов пустой строки.
- `node --experimental-strip-types --experimental-vm-modules artifacts/fixes-1.55-integration.mjs` проверяет реальные модули с заменой host API: две вкладки, ошибку записи без потери попытки/профиля, возобновление удаления и сбой DOM storage на native.
- `python artifacts/fixes-1.55-banner.py` проверяет неизменённый текущий Java-класс с Android/SDK doubles: видимость 0 → 4 → 0 после ошибки и успешного callback.
- Веб-сборка/TypeScript и две подписанные Android-сборки проверяются отдельно. Телефон не использовался; реальное сетевое заполнение рекламы остаётся проверкой на устройстве.
