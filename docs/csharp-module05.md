# Курс C#: модуль 5 — Методы и параметры

В существующий курс `csharp-foundations-v2` добавлен пятый модуль. Версия содержимого — 5. Всего: 5 модулей, 41 урок, 82 обучающие мини-проверки и 305 оцениваемых вопросов (387 заданий с учётом тренировок).

Новый модуль включает 9 уроков, 18 мини-проверок, 45 итоговых вопросов уроков и контрольный тест на 20 вопросов. Всего 83 вопроса, из них 10 с несколькими правильными вариантами.

1. Объявление, вызов и устройство метода.
2. Возвращаемые значения, return и void.
3. Передача аргументов по значению.
4. Модификаторы ref, out, in и ref readonly.
5. Переменное количество аргументов и params.
6. Необязательные и именованные аргументы.
7. Перегрузка методов и выбор перегрузки.
8. Локальные функции и область видимости.
9. Рекурсия и стек вызовов.

Все исходные ID, теория и кодовые примеры сохранены. У вопроса M05-L01-P2 есть одно редакторское исправление: определение PrintLine из следующего раздела продублировано в самом вопросе, без вызовов и комментария с результатом. Теперь вопрос можно решить до чтения следующего шага; исходный Markdown сохранён без изменений.

Импортёр поддерживает ключи «Правильный ответ», «Объяснение», «Неверные альтернативы» и новые заголовки мини-тестов. Ответы сверены с ключом. Правила оценки не изменены: тренировочные вопросы не влияют на точность, итоговые тесты отправляются целиком, первая и лучшая попытки сохраняются отдельно.

Модули 1–4 не изменились; ответы, результаты и доступ к курсу сохраняются. Повторно покупать курс не нужно, повторная награда за тот же курс не выдаётся. Общий прогресс пересчитывается с учётом новых заданий.

12 исходных файлов находятся в `server/theory-source/csharp-module05`. Команды: `npm.cmd run content:import:csharp`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run content:publish`. Повторный импорт тех же материалов не повышает версию. README и ключ не показываются как учебные страницы; ответы и объяснения включены в данные для офлайн-проверки.

APK 1.37 содержит четыре модуля; для пятого потребуется следующая сборка приложения либо обновление контента в клиенте, подключённом к серверу. Добавлен [модуль 6](csharp-module06.md). APK 1.38 содержит шесть модулей и 48 уроков. Модули 7–19 пока не добавлены.
