## Проверка примеров C#

Воспроизведение: `node --experimental-strip-types scripts/check-csharp-batch01.mjs`. Требуется установленный .NET 10 SDK; NuGet-источники для проверочного проекта отключены. Скрипт используется только разработчиком и не подключён к приложению или API.

- Присваивание `double` в `int`: исходная ошибка CS0266; явное приведение даёт 19, оба округления дают 20, `int.Parse(double)` не компилируется (CS1503).
- Короткое замыкание: вывод `True:1`; контрольная замена `&&` на `&` вызывает DivideByZeroException.
- Switch expression: оба разрешённых порядка точных веток дают `ship`; универсальная ветка перед ними делает точные ветки недостижимыми (CS8510 в синтаксически корректном контрольном примере).
- Параметры: вывод `3:11`. Инструментированный пример отдельно подтверждает локальную копию 3 при исходном count=1, изменение count через ref до 3, общий элемент 7 после ReplaceCopy и замену ссылки на массив с 11 через ReplaceRef.
- Индексация: исходный `^0` и `Length` вызывают IndexOutOfRangeException; `^1` и `Length-1` работают для длин 1, 3 и 5. `^2` даёт предпоследний элемент, фиксированный индекс 2 не работает для длины 1.

Результаты и отдельные журналы компиляции/выполнения: `artifacts/csharp-batch01-sdk/`. Проверка сценариев не превращает учебный интерфейс в компилятор или отладчик.
