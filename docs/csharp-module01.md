# Новый курс C#: модуль 1

В курс `csharp-foundations-v2` добавлен модуль «Введение в C# и .NET». Это новый набор материалов, прежние удалённые курсы не восстанавливаются.

Состав: 7 уроков, 14 обучающих мини-проверок, 35 итоговых вопросов уроков и 20 вопросов контрольного теста модуля. Три контрольных задания допускают несколько правильных вариантов. Остальные задания — выбор одного ответа, включая задачи по чтению кода.

Уроки:

1. Что такое C# и .NET.
2. SDK, Runtime, CLR, IL и JIT.
3. Компиляция, запуск и публикация.
4. Структура проекта и файл .csproj.
5. Точка входа: Main и top-level statements.
6. Пространства имён и using.
7. Комментарии, документация и организация кода.

## Правила проверки

Мини-проверки идут между частями теории, показывают объяснение после проверки ответа и допускают повторение. В общую точность они не входят. Итоговые тесты уроков и контрольный тест модуля отправляются целиком, объяснения и правильные варианты появляются после отправки всех ответов.

Множественный выбор засчитывается только за точный набор всех правильных вариантов без лишних; порядок выбора не важен. Частичных баллов нет. У контрольного теста показывается рекомендуемый порог 80%; результат ниже порога сохраняется и допускает пересдачу, сам по себе он не блокирует навигацию.

Для каждого оцениваемого теста отдельно сохраняются первая попытка, лучший и последний результат. Пересдача не перезаписывает первую попытку и не удаляет ответы других уроков. Этот модуль содержит 55 оцениваемых вопросов; после добавления третьего весь курс содержит 180. Общая оценка рассчитывается по всем оцениваемым вопросам, награда за курс — по прежнему правилу от 80% по всем оцениваемым вопросам. Работа над ошибками не меняет исходный результат.

Прогресс прохождения и точность различаются: ответы на мини-проверки учитываются в продвижении, но не в точности. Досрочная сдача содержит оцениваемые вопросы всех добавленных модулей (сейчас 180) и позволяет пропустить обучение, как и прежде. Пропуски в финальной сдаче не допускаются: нужно ответить на все оцениваемые задания.

## Повторный импорт

Исходные 10 Markdown-файлов сохранены в `server/theory-source/csharp-module01`. Импортёр читает семь уроков, контрольный тест и ключ, сохраняет исходные ID заданий и проверяет соответствие всех 69 вопросов ответам:

```powershell
npm.cmd run content:import:csharp
npm.cmd test
npm.cmd run build
npm.cmd run content:publish
```

Импортёр `scripts/import-csharp-course.mjs` собирает три модуля и повышает версию при изменении содержимого. Первый аргумент позволяет указать общий каталог исходников с подпапками `csharp-module01`, `csharp-module02`, `csharp-module03`. Временные пути пользовательского компьютера для повторного импорта не нужны.

Файл README описывает комплект и будущие модули; файл ключа нужен только для импорта. Они не отображаются как уроки. Пользователь видит теорию, задания и объяснения к отправленным ответам. Для офлайн-проверки правильные ответы и объяснения входят в данные курса; скрытие разбора до отправки — поведение интерфейса, а не защита содержимого файла.
