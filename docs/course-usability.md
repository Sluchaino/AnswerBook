# Прохождение курса: теория в тестах и прогресс модулей

В каждом тесте можно раскрыть «Посмотреть теорию и примеры к тесту». Показываются все теоретические разделы текущего урока, а для контрольного теста — текущего модуля. Вопросы, ответы и служебные ключи в справку не включаются. Раздел раскрывается на месте, выбранные ответы сохраняются. Текст справки загружается в DOM при раскрытии.

Прогресс текущего модуля — доля проверенных оцениваемых заданий. Ошибка тоже засчитывается в прохождение, точность остаётся отдельной метрикой. Мини-проверки и ещё не отправленные ответы не увеличивают этот показатель. Модуль завершён после проверки всех его оцениваемых заданий. Счётчик завершённых модулей показывается в карточке курса и при прохождении.

В интерфейсе курса csharp-foundations-v2 модуль m01 «Введение в C# и .NET» перенесён в конец. Новый курс начинается с m02 «Типы данных и переменные». Применяется одинаково к встроенным и загруженным материалам. Порядок исходных Markdown и серверного JSON, идентификаторы уроков и вопросов остаются прежними; существующее сохранение продолжает текущий урок. Новая покупка не требуется.

Проверки: npm.cmd test (221 тест), npm.cmd run build, npm.cmd run lint; мобильный браузер 390×844, раскрытие справки и новый порядок модулей. APK не пересобирался: изменения интерфейса появятся на телефоне после установки новой сборки.
