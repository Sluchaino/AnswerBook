# Аудит форматов интерактивов ASP.NET Core

> Историческая первая переработка. Актуальный подбор без одинаковой пропорции типов описан в [подборе по целям уроков](aspnet-interactive-selection.md).

29 октября 2026 года проверены все 27 модулей и 135 заданий. Однообразными оказались только модули 16–25: по пять matching. Остальные модули уже содержали минимум три разных формата.

В модулях 16–25 заменено по два упражнения: одно на code-debug и одно на sequence. Теперь каждый из этих модулей содержит три сопоставления, исправление ошибки и последовательность. Во всех 27 модулях по пять упражнений, минимум три формата и максимум один интерактив на урок.

| Модуль | Исправление ошибки | Последовательность |
|---|---|---|
| 16 | Отключённая проверка audience JWT | Authorization Code + PKCE |
| 17 | Отсутствующий фильтр владельца | Проверка запрета изменения чужого ресурса |
| 18 | HttpOnly отключён | Приём недоверенного файла |
| 19 | Токен отмены потерян в HTTP-вызове | Retry идемпотентного GET в пределах бюджета |
| 20 | Секунды записаны в Histogram с unit ms | Диагностика инцидента |
| 21 | Result блокирует async-обработчик | Проверка гипотезы о производительности |
| 22 | Повторное использование номера protobuf | WebSocket lifecycle |
| 23 | Тест автоматически следует за редиректом | Изолированный тест PostgreSQL |
| 24 | Нулевое резервирование разрешено | Эволюционное изменение границы |
| 25 | Контейнер запускается от root | Сборка, тесты и выпуск артефакта |

Идентификаторы и позиции упражнений сохранены; версии двадцати изменённых упражнений повышены. Сохранённые состояния изменённых упражнений сбрасываются по fingerprint штатным механизмом. Обычные ответы, прежние результаты курса и решения остальных упражнений сохраняются. Исторический снимок до переработки — `tests/fixtures/aspnet-interactives-before-variety.json`.

Проверки включают полноту аудита, разнообразие и лимиты всех модулей, неизменность всех теоретических и тестовых блоков, правильные/неправильные решения и миграцию сохранённых попыток. Полная компиляция всех приведённых фрагментов C#, protobuf и сборка контейнеров не выполнялись. Облако не обновлено, JSON для загрузки и APK до отдельного запроса не выдаются.

Документы `aspnet-v2-modules16-25.md` и `aspnet-v2-directory16.test.mjs` относятся к первоначальному импорту; описание всех пяти упражнений как сопоставлений в историческом отчёте заменено этим аудитом.
