# Курс C#: модуль 13 — LINQ

Добавлены десять уроков: основы LINQ, Where, Select, SelectMany, сортировка, поиск и проверки, группировка, соединения и множества, агрегаты, отложенное выполнение и производительность.

В модуле 20 мини-проверок без оценки, 50 итоговых вопросов уроков и 20 вопросов контрольного теста. Все задания с одним правильным ответом. Курс версии 13 содержит 13 модулей, 115 уроков, 230 обучающих и 835 оцениваемых вопросов.

Оригиналы Markdown сохранены в server/theory-source/csharp-module13. Импортёр поддерживает локальные обозначения М1/И1/К1 и сверяет текстовый ключ с JSON-таблицей, включая поле exam. Служебный ключ и README не отображаются в уроках. Примеры кода и заключительные рекомендации сохранены. Объяснения раскрываются по правилам соответствующего теста, данные проверки доступны офлайн.

Первые двенадцать модулей не изменены. Сохраняются ответы, результаты, первая и лучшая попытки; прогресс пересчитывается с учётом нового материала. После экзамена модуля 12 открывается теория модуля 13. Повторная покупка не требуется.

Импорт: npm.cmd run content:import:csharp. Проверки: npm.cmd test, npm.cmd run build, npm.cmd run lint. Публикация: npm.cmd run content:publish. Повторный импорт сохраняет версию, если содержимое не менялось.

APK 1.39 содержит первые восемь модулей. Для модулей 9–13 нужна новая сборка либо загрузка курса в клиенте с настроенным сервером. APK в этой итерации не пересобирался.
