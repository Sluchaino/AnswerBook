# Исправления 1.53

Радиокнопки и checkbox больше не скрывают баннер. Ранее любой HTMLInputElement считался полем текстового ввода; теперь учитываются только редактируемые текстовые поля. Скрытие при открытых диалогах и списках сохранено.

В CodeDebugInput подпись и код исправления объединены в одну колонку рядом с радиокнопкой. Пустые блоки кода не отображаются. Длинные строки прокручиваются внутри блока кода, не растягивая страницу.

Добавлен build type screenshots: тот же package, версия и релизная подпись, но ADS_ENABLED=false. Нативный плагин не инициализирует рекламный SDK и сообщает веб-интерфейсу, что место под баннер не требуется. Для публикации используется обычный release; screenshots предназначен для подготовки изображений магазина.

Проверки: 525 тестов, обе Android-сборки, подпись и отсутствие отладочного режима, соответствие 25 веб-ресурсов APK текущей сборке. Семь интерактивных механик показаны в браузерном стенде на ширинах 320, 360 и 412 px; горизонтального переполнения страницы не обнаружено. Исправление с подписями вариантов и без них проверено отдельно. Физическим телефоном в этом изменении не управляли; повторную проверку реального баннера выполняет пользователь.
