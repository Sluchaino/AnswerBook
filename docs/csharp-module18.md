# Курс C#: модуль 18 — Управление памятью в .NET

Девять уроков: стек и куча, размещение объектов и корни GC, основы сборки мусора, поколения и режимы GC, LOH/POH, финализаторы, управляемые утечки, Span/Memory, ref struct и stackalloc.

Добавлены 18 тренировочных вопросов, 45 итоговых вопросов уроков и 20 вопросов контрольного теста. Все задания с одним правильным ответом. Курс версии 18 содержит 18 модулей, 167 уроков, 334 тренировочных и 1195 оцениваемых вопросов.

Оригиналы Markdown сохранены в server/theory-source/csharp-module18. Импортёр сверяет текстовые ответы с JSON-словарями lesson_01–lesson_09 и exam. Служебные файлы и редакторские источники не отображаются в уроках. Примеры и разделы «Перед следующим уроком» сохранены. Объяснения раскрываются по правилам соответствующего теста; прохождение доступно офлайн.

Первые 17 модулей не изменены. Проверены перенос ответов, результатов, первой и лучшей попыток и переход от экзамена модуля 17 к теории модуля 18. Прогресс пересчитывается с учётом нового материала.

Импорт: npm.cmd run content:import:csharp. Проверки: npm.cmd test, npm.cmd run build, npm.cmd run lint. Публикация: npm.cmd run content:publish. Повторный импорт не меняет версию без изменения содержимого.
