# Сервер контента AnswerBook

Все существовавшие учебные курсы и исходная теория удалены 26 октября 2026 года по запросу владельца. После удаления добавлены девятнадцать новых модулей курса C#; пустой каталог также является корректным состоянием. Открытые вопросы в разделе «Каталог» сохранены.

## Запуск

```powershell
npm.cmd run content:publish
npm.cmd run server:dev
```

В другом терминале запустите npm.cmd run dev. Vite перенаправляет /api на http://127.0.0.1:5129. На телефоне для обновлений нужен настроенный адрес сервера в сборке; установленный ранее APK сохраняет встроенные материалы до обновления самого приложения.

## Данные

GET /api/catalog возвращает courses, directions, removedIds, schemaVersion и revision. removedIds содержит идентификаторы удалённых курсов. Обновлённый клиент очищает их из скачанного каталога и контрольных сумм, в том числе при офлайн-запуске. При ошибке сохранения старые данные не заменяются частичным обновлением. Возврат к старой ревизии сервера не восстанавливает удалённые курсы.

Серверные файлы прежних редакций также удалены. Обновления публикуются атомарно; пустой каталог допускается. Для будущих курсов сохранён JSON-протокол и сервер ASP.NET Core. Новые файлы помещаются в server/course-source и публикуются командой content:publish. Используйте новые уникальные ID, не совпадающие с удалёнными. Не создавайте повторно старые курсы из архивов.

Кеш курсов отделён от личных ответов. Профессии сохраняются, ссылки на удалённые курсы из них исключаются. Баланс монет и история занятий не обнуляются; удалённые покупки больше не повышают стоимость будущих курсов. Пользовательские материалы с другими ID сохраняются.

## Yandex Object Storage

Публичный каталог: https://answerbook-content-2026.storage.yandexcloud.net/catalog.json.
Адрес хранится в `src/data/content-host.json` и применяется по умолчанию в новых сборках сайта и Android. `VITE_COURSES_URL` позволяет переопределить его. В режиме разработки сайт продолжает использовать `/api/catalog` локального API для предпросмотра неопубликованных материалов.

Проверка опубликованных файлов: `npm.cmd run content:verify:s3`. Команда скачивает каталог и курсы в память, проверяет CORS для сайта и Android, размеры, SHA-256 и формат штатным загрузчиком. Личные данные, локальный кеш и объекты в облаке не изменяет.

При публикации сначала загружайте новые файлы `courses/`, затем заменяйте `catalog.json`. Исходные файлы и приложение загружать в бакет не нужно. При публичном чтении курсы доступны по прямым ссылкам; локальная покупка за монеты не является серверной защитой доступа. Ответы и личные данные на сервер контента не отправляются.

## Выборочная библиотека (Android 1.43)

В сборку входит только `src/data/download-catalog.json`: карточки, описание и структура курса, версия, размер и SHA-256 пакета. Теория, вопросы тестов и данные интерактивов не импортируются в клиентскую сборку. Полные авторские источники остаются в `server/course-source/` для последующей публикации.

Автоматически обновляется только каталог. «Скачать» загружает один выбранный курс, «Обновить» появляется при новой версии скачанного курса. До успешного сохранения новой версии работает старая. «Удалить» после подтверждения убирает пакет и его предыдущие редакции из кеша, сохраняя ответы, результаты, историю занятий, профессии и сводку прогресса. Повторное скачивание восстанавливает прохождение по сохранённым ID. Монеты и покупки отключены.

Библиотека атомарно сохраняется в IndexedDB на сайте и в файле приложения с указателем Preferences на Android. Мутации выполняются последовательно. Старый кеш полного набора мигрирует как уже скачанные материалы; ответы не удаляются. Удалённые пользователем курсы не скачиваются при автоматическом обновлении каталога. На сайте материалы доступны в открытом приложении, однако офлайн-запуск самой страницы после закрытия браузера требует отдельного PWA-кеша оболочки.

Публикация: `npm.cmd run content:publish`, затем `npm.cmd run content:prepare:s3`. В пакеты каталога теперь включается лёгкое поле summary; для будущих новых курсов и версий нужно загружать новый catalog.json вместе с соответствующими пакетами. При первом переходе на библиотеку достаточно заменить catalog.json: существующие неизменные пакеты в облаке переиспользуются. Уже установленный APK нужно обновить.
