# Новая программа ASP.NET Core и описание курсов

28 октября 2026 года добавлен отдельный курс `aspnet-core-foundations-v2` v6. Старые курсы ASP.NET Core и Python остаются удалёнными; их ID сохранены только для очистки скачанных копий. C# v114 и его упражнения не изменены.

Первый модуль содержит семь уроков по семи присланным файлам, 14 мини-проверок, 35 итоговых вопросов уроков и 20 вопросов контрольного теста. Добавлены пять интерактивов, максимум один в уроке: уровни платформы (урок 1), HTTP-сообщения (2), порядок middleware (3), сборка запуска хоста (5), исправление ответа о создании (6). Уроки 4 и 7 не дополнены искусственными заданиями или уроками.

Исходные материалы сохранены в `server/theory-source/aspnet-core-v2-module01/`. Импорт: `npm run content:import:aspnet`. Служебные ключи и источники не выводятся в ученической теории. Исходные примеры сохранены.

## Программа и доступность

Поле `plan` хранит предварительные знания и программу из 27 модулей с названиями 270 уроков. Это метаданные, а не пустые учебные модули: будущие уроки не участвуют в оценке, прогрессе или наградах. Доступность определяется наличием реальных загруженных материалов. Несмотря на пометки completed в присланном плане модулей 2–4, их файлов нет, поэтому модули 2–27 показывают «Скоро появится».

Нажатие на карточку или фокусируемое название открывает описание курса и раскрываемую программу до покупки. Кнопки начала, результата, покупки и досрочной сдачи сохраняют свои действия. У C# программа строится из 19 существующих модулей без изменения источника. Просмотр описания не начинает попытку, не списывает монеты и не регистрирует занятие. Владельцу открытого курса доступна кнопка открытия модуля с первого теоретического шага. Завершённые попытки продолжают открывать сохранённый результат.

План входит в версионированный JSON и сохраняется в офлайн-кеше вместе с курсом. Обновление материалов меняет доступность без изменения UI. Каталог сервера и резервная публикация имеют revision 190.

## Проверки

- 378 автоматических тестов; семь API-проверок редактора. Проверены запрет неправильных/повторных ID плана, соответствие загруженным урокам, сохранение плана в публикации и кеше, исключение будущих уроков из оценки.
- Веб-сборка проходит; lint содержит восемь прежних предупреждений.
- `scripts/check-aspnet-v2.mjs`: 15 успешных SDK/HTTP-сценариев, включая все десять полных Program.cs, порядок middleware, собранный запуск хоста и четыре варианта исправления ответа POST.
- На ширине 390 px проверены обе карточки, программа 1/27 для ASP.NET и 19/19 для C#, раскрытие будущих уроков, покупка за тестовые монеты, открытие первого шага модуля. Все пять упражнений проверены с неверным/правильным ответом, восстановлением и сбросом. Консоль без ошибок, горизонтального переполнения нет.
- Повторный импорт и публикация сохраняют v6 и пять упражнений. Контрольные суммы C# и обоих опубликованных payload сверены отдельно.

APK не пересобирался. Пользовательский код в приложении не выполняется: SDK-проверка относится только к фиксированным учебным примерам.
