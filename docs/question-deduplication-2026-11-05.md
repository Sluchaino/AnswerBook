# Короткие уникальные вопросы каталога

Редакция 7 заменяет редакцию 6. Вручную сопоставлены вопросы всех 53 тем, включая повторы между общими и специализированными темами.

- Было 968 вопросов, осталось 685; удалены 283 смысловых дубля.
- Формулировки сокращены до общих открытых вопросов. Самая длинная — 109 символов. Это результат текущей редактуры, а не требование делать любой будущий вопрос предельно коротким.
- Сохранены предложенные пользователем формулировки про string.Length и массивы T[,] / T[][].
- Пересечение терминов само по себе не считалось дублированием: например, причины коллизий хеша отличаются от устройства Dictionary, а async/await — от ConfigureAwait(false).
- Канонические вопросы об одном предмете распределены по профильным темам вместо копирования в несколько тем. Все 53 темы сохранены.
- Карта `src/lib/questionRedirects.ts` связывает каждый удалённый ID непосредственно с живым вопросом. Старые отметки «знаю» переводятся на канонический ID без изменения пользовательских вопросов и настроек тем.
- Начатый опрос сохраняет прежний снимок, формулировки и ответы. Новые опросы используют сокращённый каталог; старый снимок не редактируется автоматически.
- Скрипт расширения каталога пропускает удалённые дубли и сохраняет текущие короткие формулировки. Повторная генерация проверена: набор ID и текстов не изменился.
- Курсовые тесты, интерактивы и материалы курсов не изменялись. Правило количества интерактивов в модуле не относится к числу открытых вопросов каталога.

Проверки: сборка успешна; 511 тестов без ошибок, включая перенос отметок, отсутствие циклов и удалённых целей в карте замен, сохранение активного опроса и уникальность нормализованных текстов. Автоматическая проверка текста дополняет смысловую вычитку и не заменяет её.

Локальный отчёт с каждой парой «удалённый вопрос → оставшийся»: `artifacts/question-deduplication/report.json`. Оригинал перед изменениями: `artifacts/question-deduplication/catalog-before.json`. Эти файлы находятся в исключённой из Git папке artifacts.
