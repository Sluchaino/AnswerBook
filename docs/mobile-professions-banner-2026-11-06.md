# Профессии и баннер — 1.48

- В редакторе профессий доступны только учебные курсы каталога. Поле произвольного курса удалено.
- Прежние произвольные записи и темы не показываются и не входят в прогресс. Исходные сохранения остаются читаемыми; при сохранении изменений профессия содержит только учебные курсы. Сохранения прохождения курсов не удаляются.
- Закреплённый баннер использует BannerAdSize.fixed(context, availableWidthDp, 50). Ограничение ширины 320 dp снято; креатив не растягивается вручную. Наличие подходящего объявления определяется SDK и рекламным аукционом.
- Между рекламным контейнером и нижним меню — 6 CSS px. Отступ учитывается в резерве для прокрутки.
- Выбор обработки данных в этой версии не изменён: отказ не отключает рекламу. setUserConsent(false) не означает отсутствия любой обработки данных SDK.

## Документация

- https://ads.yandex.com/helpcenter/ru/easy/integration/android/formats/banner — fixed для закреплённых областей, минимальная высота 50 dp.
- https://ads.yandex.com/helpcenter/ru/dev/android/gdpr — пример согласия в контексте GDPR, передача выбора через setUserConsent. Эта страница не доказывает универсальную обязанность показывать отдельное окно всем пользователям из РФ.

Требуется проверка реального заполнения рекламы и отступов на телефоне. Debug APK использует тестовый рекламный блок.
