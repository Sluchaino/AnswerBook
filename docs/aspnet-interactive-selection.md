# Подбор интерактивов ASP.NET Core по целям уроков

Проверены все 27 модулей. Содержательные задания модулей 1–15 оставлены; модули 16–27 переработаны без единой пропорции форматов. Всего 135 заданий; по пять на модуль, не больше одного на урок.

В этой итерации заменены 14 заданий: 6 архитектурных схем, 4 трассировки, 3 сборки кода и 1 преобразование данных. Теория, обычные вопросы, размещение и идентификаторы сохранены. Для изменённых упражнений повышена версия; их прежние ответы сбрасываются штатным механизмом fingerprint. Остальные решения и результаты курса сохраняются.

Трассировки очереди, одноразового refresh token и кеша проверены реальным запуском на .NET 10. Это явно описанные упрощённые модели, а не реализации OAuth, HybridCache или distributed cache. Публикация в облако и выдача JSON/APK отложены до запроса владельца.
