# Реклама после отказа от использования данных для подбора

Текущая реализация заменяет прежний вариант, в котором отказ отключал все баннеры. Это было решением приложения, а не установленным требованием RuStore.

- Пользователь выбирает использование данных для подбора рекламы. При отказе баннеры остаются включёнными; в YandexAds передаётся setUserConsent(false), а дополнительная рекламная аналитика отключается через setAppAdAnalyticsReporting(false).
- setUserConsent не объявляется универсальным переключателем любого сбора данных: документация Яндекса описывает его в контексте согласия и GDPR-регионов. Не обещается полное отсутствие технических данных или анонимность рекламы во всех регионах.
- Политика и экран выбора прямо сообщают, что отказ не отключает баннеры. Новая версия записи выбора запрашивается повторно, чтобы не трактовать прежний отказ от всего рекламного SDK как новый выбор без уведомления.
- До выбора и во время модальных окон SDK не получает запросов загрузки баннера. Геолокация отключена в обоих вариантах.
- Резерв области рекламы уменьшен с 112 до 56 CSS px; после измерения устанавливается фактическая высота компактного баннера. Вместо адаптивного sticky используется фиксированный формат 320×50 dp с центрированием. Креатив не масштабируется и не обрезается. Документация Яндекса указывает минимальную высоту баннера 50 dp.
- Из интерфейса и политики убраны упоминания проверки ответов через ИИ; отметки об ИИ-подготовке учебных материалов сохранены.

Источники:

- https://ads.yandex.com/helpcenter/ru/dev/android/gdpr
- https://ads.yandex.com/helpcenter/ru/easy/integration/android/formats/banner
- https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps

Выдачу реальной рекламы во всех регионах нельзя подтвердить unit-тестом или по ID рекламного блока; она зависит также от правил сервиса, модерации, наличия сети и рекламного спроса.
