# Курс C#: модуль 4 — Управляющие конструкции

В существующий курс `csharp-foundations-v2` добавлен четвёртый модуль. Версия содержимого — 4. Всего: 4 модуля, 32 урока, 64 обучающие мини-проверки и 240 оцениваемых вопросов.

Новый модуль содержит 8 уроков, 16 мини-проверок, 40 итоговых вопросов уроков и контрольный тест на 20 вопросов. Всего 76 заданий, из них 9 с несколькими правильными вариантами.

1. Условные операторы if, else if и else.
2. switch: оператор и выражение.
3. Цикл for и управление счётчиком.
4. Циклы while и do-while.
5. Цикл foreach и обход последовательностей.
6. Управление выполнением: break, continue, return.
7. Основы pattern matching.
8. Составные алгоритмы и ошибки управления потоком.

Теория и все кодовые примеры перенесены из предоставленных файлов. Ключи с заголовком «Почему» поддерживаются импортёром наряду с «Обоснование». Все ID заданий сохранены. Мини-проверки не влияют на точность, итоговые и контрольные тесты отправляются целиком; первая и лучшая попытки хранятся отдельно.

Модули 1–3 сохранены без изменений. Предыдущие ответы и результаты сохраняются, общий процент пересчитывается с учётом нового модуля. Повторно покупать курс не нужно; дополнительная награда за ранее зачтённый курс не выдаётся.

Исходные 11 Markdown-файлов находятся в `server/theory-source/csharp-module04`. Импорт и публикация: `npm.cmd run content:import:csharp`, `npm.cmd test`, `npm.cmd run content:publish`. Повторный импорт неизменного содержимого сохраняет версию. README и служебный ключ не отображаются отдельными учебными страницами; ответы и объяснения включены в данные для офлайн-проверки.
