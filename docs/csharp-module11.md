# Курс C#: модуль 11 — Коллекции и итераторы

Добавлен одиннадцатый модуль курса csharp-foundations-v2. Версия содержимого — 11. Всего: 11 модулей, 95 уроков, 190 обучающих мини-проверок и 695 оцениваемых вопросов (885 заданий).

Новый модуль: 10 уроков, 20 мини-проверок, 50 итоговых вопросов уроков и контрольный тест на 20 вопросов. Все 90 заданий имеют один правильный вариант.

1. List<T>: динамический массив.
2. Dictionary<TKey,TValue>: словарь по ключу.
3. HashSet<T>: множество уникальных элементов.
4. Queue<T> и Stack<T>: порядок обработки.
5. IEnumerable<T>, IEnumerator<T> и foreach.
6. Интерфейсы коллекций и API.
7. Итераторы и yield return.
8. Сравнение и сортировка: IComparer<T> и IEqualityComparer<T>.
9. Изменение коллекций при перечислении.
10. Выбор коллекции и сложность операций.

13 исходных Markdown-файлов сохранены в server/theory-source/csharp-module11. Новый формат нумерации 1.M1, 10.F5, E20 преобразуется в стабильные ID M11-L01-P1, M11-L10-F5, M11-EX-20. Обычные маркированные варианты A–D поддерживаются импортёром; внутри кодовых блоков текст не преобразуется.

Все ответы сверены с ключом, все примеры кода сохранены. Заключительные разделы «На что обратить внимание», расположенные в исходниках после итогового теста, перенесены в завершающую часть теории перед ним. Служебный ключ и README не показываются отдельными учебными страницами. Перемешивание вариантов сохраняет правильность по исходной идентичности ответа, а не по его позиции на экране.

Первые десять модулей не изменились. Сохранённые ответы, результаты, первая и лучшая попытки переносятся. Доступ к курсу сохраняется, повторная покупка не нужна. После контрольного теста модуля 10 открывается теория модуля 11. Общий прогресс учитывает новые задания; повторная награда за тот же курс не выдаётся.

Мини-проверки не входят в точность, итоговые тесты отправляются целиком. Закреплённая строка стрелок и дизайн не менялись. Импорт: npm.cmd run content:import:csharp. Проверки: npm.cmd test, npm.cmd run build. Публикация: npm.cmd run content:publish. Повторный импорт без изменений сохраняет версию.
