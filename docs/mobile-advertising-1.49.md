# Изменения 1.49

Окно выбора обработки данных для рекламы и пункт «Настройки рекламы» удалены. Реклама запускается без запроса выбора, SDK всегда получает setUserConsent(false) и setAppAdAnalyticsReporting(false). Старые разрешения не используются. Это не гарантирует отсутствия технической обработки данных SDK. Обновлена политика до 2026-11-06.3 и её публичная HTML-версия.

В редакторе профессии показываются только направления, содержащие доступные в каталоге учебные курсы. Пустые направления больше не отображаются.

Сборка и 522 теста прошли. Проверка отображения рекламного объявления на физическом телефоне остаётся за пользователем. Debug APK содержит демонстрационную рекламу.
