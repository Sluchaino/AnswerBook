## C# 14 / .NET 10

`node --experimental-strip-types scripts/check-csharp-batch02.mjs` проверяет только заранее заданные авторские программы. Это developer-only скрипт, не часть приложения/API. Источники NuGet в проверочном проекте отключены. SDK **10.0.400**, язык **14.0**, target **net10.0**: **53 из 53** случаев прошли.

- Конструкторы: `inner`, `outer`, `untitled`. Код условий сверяется с проверяемым примером; последовательность описывает именно тела этой this-цепочки.
- readonly: исходный код и повторное присваивание массива дают CS0191. Исправление даёт `9:2`, сохраняет идентичность массива; неверные Clear/индекс меняют результат на `0:0`/`1:9`.
- Полиморфизм: `dog`, `base`, `derived`, реальный тип Dog. Контрольная замена override на new меняет первый вывод на animal; попытка override невиртуального Describe даёт CS0506. Перегрузок в примере нет.
- Boxing: исходный `(long)boxed`, `(long?)boxed` и распаковка в double вызывают InvalidCastException. Три корректных исправления дают 7: извлечь int и расширить до long, сделать это явно или вызвать Convert.ToInt64. Отдельно проверены непустой/пустой nullable boxing и NullReferenceException при распаковке null в int.
- Generic-метод компилируется и выдаёт `A-7`. Без new() — CS0304, без IHasCode — CS1061, с new() перед интерфейсом — CS0401.
- Вариантность: положительные присваивания IEnumerable<Dog> → IEnumerable<Animal> и IComparer<Animal> → IComparer<Dog>; отрицательные List<Dog> → List<Animal>, IEnumerable<int> → IEnumerable<object> и обратные направления интерфейсов. Проверены именно ошибки компиляции CS0029/CS0266.
- Словарь: три допустимых исправления × три ключа (`book`, `pen`, `empty`) дают соответственно -1/4/0. Исходный индексатор бросает KeyNotFoundException. Словарь после чтения не пополняется; Count и fallback 0 отвергаются по контракту. ContainsKey допустим: условие явно исключает конкурентную модификацию и не требует одного поиска.
- Замыкание: `5`, `6`, `6`, `1`. Инструментированный пример подтверждает count=5/6 при snapshot=1; контрольная лямбда с отдельной копией даёт другой вывод.
- Событие: исходный код `AB`, отписка сохранённым first — `B`, отписка second — `A`, повторная подписка first — `ABA`. Отдельная лямбда не снимает нужную подписку. Проверены все предложенные исправления.

Во время подготовки SDK выявил ошибку в кандидате: `new Action(first)` не эквивалентен исходной подписке в данном коде и оставляет `AB`. Эталон исправлен **до публикации**; этот вариант теперь неверный и объяснён. Не делается обратное чрезмерное обобщение «разные экземпляры делегатов всегда не равны»: отдельная проверка двух явно созданных делегатов одного метода показывает ReferenceEquals=False, Equals=True.

Повторно запущены **22 из 22** случаев 7Б.1. Итого в SDK-проверках двух партий **75** успешных случаев. Журналы и результаты: `artifacts/csharp-batch02-sdk/`, `artifacts/csharp-batch02-sdk-log.txt`, аналогичные пути batch01.

## Интерфейс и ограничения

Использован изолированный предпросмотр настоящего ExercisePlayer в редакторе на отдельном порту 59022. Он не обращается к учебному прогрессу, серии или монетам. Контент публиковался через API; UI не использовался для ручной записи JSON.

Все девять открыты в мобильном iframe 390px. Успешно пройдены: обе трассировки до завершения (у полиморфизма дополнительно проверены неверное предсказание, повтор и сброс), четыре задания поиска ошибки, сопоставление вариантности, сборка generic-метода и порядок this-конструкторов. Для generic-кода проверены неверный начальный порядок и повторное исправление. На desktop проверены подробные таблицы статических/фактических типов и общая ячейка замыкания. При 390px обе трассировки имеют ширину документа 375px с полосой прокрутки; горизонтального переполнения страницы нет. Ошибок в журнале браузера нет. Скриншот: `artifacts/csharp-batch02-mobile-closure.png`. Временная вкладка и сервер проверки закрыты; обычный учебный профиль не использован.

Снимки трассировки заранее подготовлены, это не отладчик. Общая ячейка замыкания обозначает семантику захвата, а не обязательную реализацию компилятора. Точный момент GC и многопоточность не моделируются. Код в учебном приложении не выполняется. Условия явно задают известный упакованный тип и синхронность там, где это необходимо; новые задания не являются защищённым экзаменом.

В m13–m19 ничего не создано. Остаётся план десяти заданий: deferred LINQ, using, AAA, тестовые границы, WhenAny, гонка инкремента, SemaphoreSlim, GC roots, Span и with. Целевой ориентир — **49** после будущей партии. 7Б.3 автоматически не начинался.
