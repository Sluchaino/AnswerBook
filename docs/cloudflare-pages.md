# Публикация КодШаг на Cloudflare Pages

Опубликовано 8 ноября 2026 года (Москва).

- Проект Cloudflare Pages: `kodshag`, Direct Upload.
- Сайт: https://kodshag.pages.dev/
- Политика мобильного приложения для карточки RuStore: https://kodshag.pages.dev/privacy.html
- Cloudflare также открывает этот документ по адресу https://kodshag.pages.dev/privacy (автоматическое перенаправление с `.html`).

В Cloudflare загружены только 26 файлов итоговой папки `dist`, упакованных без родительской папки в `artifacts/kodshag-cloudflare-pages.zip`. Исходники курсов, локальные ответы, ключи подписи, пароли и сервер редактора в архив не входят. Скачиваемые курсы продолжают храниться в прежнем Yandex Object Storage; каталог открытых вопросов использует прежний источник GitHub.

Адрес политики хранится в `src/data/privacy-policy.json`, поле `publicUrl`. Его используют ссылка внизу сайта, компонент политики внутри приложения и canonical публичной страницы. Текст мобильной политики и редакция 2026-11-06.4 не изменялись. Установленные APK этой публикацией не обновляются; новая внешняя ссылка в компоненте политики войдёт в следующую сборку Android.

## Проверено после публикации

- Проверка содержимого, TypeScript и production-сборка прошли; два теста подтверждения ознакомления с политикой прошли.
- Главная страница, политика и оба входных JS/CSS-ресурса возвращают HTTP 200 и побайтно совпадают с локальной сборкой.
- Каталог курсов revision 271 доступен с нового origin; CORS разрешает загрузку. В каталоге три курса.
- В браузере публичного сайта успешно скачан C#, показана отметка доступности офлайн, открыта структура из 19 модулей. Политика открывается без входа в аккаунт.
- Для HTML и политики используется `Cache-Control: no-cache`, для файлов `/assets/*` — длительное кеширование с immutable.

HTTP-проверка: `artifacts/cloudflare-pages-verification.json`; снимок опубликованного сайта: `artifacts/cloudflare-pages-published.png`; лог сборки: `artifacts/cloudflare-pages-build.log`.

## Следующие публикации

1. Выполнить `npm run build` и проверить результат.
2. Упаковать содержимое `dist` в ZIP так, чтобы `index.html` был в корне архива.
3. В существующем проекте `kodshag` открыть создание нового production deployment и загрузить архив. Новый проект создавать не нужно.
4. После публикации проверить сайт и политику. Постоянный адрес `kodshag.pages.dev` сохраняется.

Автоматическая публикация из GitHub не подключалась. Страница политики генерируется из общего JSON командой сборки; вручную править `public/privacy.html` не нужно.
