## Восстановление старых сохранений

## Конфликт открытых вкладок

Сохранение попытки курса и профиля теперь проверяет версию прочитанных данных. Удаление создаёт устойчивую отметку изменения даже для отсутствующего сохранения. Старая вкладка больше не возвращает удалённые ответы, историю результатов или ручные отметки прохождения. При конфликте показывается сообщение с предложением переоткрыть раздел или перезагрузить страницу; данные из другой вкладки не заменяются.

Записи сериализованы; в поддерживающем Web Locks браузере проверка и запись выполняются под общим для вкладок замком. Собственные последовательные сохранения не конфликтуют друг с другом. После ошибки записи можно повторить сохранение; при этом защита от последующих внешних изменений сохраняется.

## Запуск при повреждённом профиле

Повреждённый профиль вместе с незавершённым полным удалением курса больше не прерывает запуск всех разделов. Исходный профиль сохраняется без перезаписи, а необходимая очистка ручных отметок записывается отдельно. После восстановления корректного профиля она завершается при следующем запуске. Попытка удаляемого курса очищается, остальные курсы и их прогресс сохраняются. Исправление изолирует повреждение, но не восстанавливает произвольный испорченный JSON профиля.
