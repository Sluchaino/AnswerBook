# ASP.NET Core — EF Core: продвинутые механизмы

Тринадцатый модуль добавлен по двенадцати файлам уроков, контрольному тесту и ключу. Оригиналы без изменений находятся в `server/theory-source/aspnet-core-v2-module13/`. Курс `aspnet-core-foundations-v2` v85, каталог revision 256.

Двенадцать уроков содержат 24 мини-проверки, 60 итоговых вопросов уроков и 20 контрольных — всего 104 с пояснениями. Пять интерактивов размещены по одному в уроках 2, 6, 7, 9 и 12: identity/fixup, single/split, сборка транзакционной операции, исправление concurrency token и ограничения streaming. Дополнительные уроки не создавались.

Доступны тринадцать модулей из 27: 123 урока, 65 интерактивов, 246 мини-проверок и 875 вопросов на оценку. Модули 14–27 показывают «Скоро появится». Первые двенадцать модулей и размещения их упражнений сохранены; курс C# и его sidecar сверены по SHA-256. Ключи и источники не показываются в ученической теории.

## Коррекция примеров

В двух инициализаторах Product (уроки 2 и 7) не было обязательного Sku из общей модели модуля 11. Компилятор подтвердил CS9035. При импорте добавлены учебные значения HTTP-7 и CABLE-120; исходные файлы не менялись. Проверка сохранности code fences учитывает только эти добавления.

## Проверки

- 426 автоматических тестов и семь API-проверок проходят. Веб-сборка успешна. Lint содержит восемь прежних предупреждений; сборщик предупреждает о размере основного JS-файла.
- `scripts/check-aspnet-v2-module13.mjs`: десять успешных сценариев на .NET 10 и Npgsql.EntityFrameworkCore.PostgreSQL 10.0.3. Проверены original/current values и Modified, конфликт двух tracked-экземпляров ключа, fixup и Clear, трансляция Include/filtered Include/проекций и single/split preview, агрегат Count, метаданные Guid concurrency token и отображение uint row version в xmin.
- Скомпилированы contextual fragments explicit loading, сохранения графа, транзакции и savepoints, retry с фабрикой контекстов, FromSqlInterpolated с FOR UPDATE, конфигурации индекса, streaming и пакетной обработки. Альтернативные Guid/uint-модели проверяются отдельно; для InventoryItem задано соответствие SQL-таблице и колонкам.
- Эталон транзакционного упражнения компилируется; четыре исправления token проверены через EF-метаданные. Только IsConcurrencyToken включает нужный флаг. Это не проверка настоящего lost update или атомарности на PostgreSQL.
- Реального подключения и исполнения SQL, блокировок, retry после сбоя, savepoint rollback, EXPLAIN ANALYZE, измерений N+1/p95 и streaming под нагрузкой не было. Split ToQueryString подтверждает выбранную стратегию и preview, а не число выполненных команд или консистентность снимка. Guid по-прежнему должен обновляться приложением отдельно.
- На ширине 390 px проверены правильные/неправильные решения пяти заданий, восстановление после перезагрузки и сброс рабочего ответа. Сброс сохраняет ранее полученную отметку успешного выполнения. Консоль без ошибок, горизонтального переполнения нет.
- Повторный импорт и публикация идемпотентны. Основной и резервный каталоги revision 256 совпадают; payload сверены по SHA-256.
