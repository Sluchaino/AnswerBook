# Открытые вопросы по курсам C# и ASP.NET Core

Каталог вопросов: `src/data/questions.json`, revision 5.

- Сохранены все 738 прежних вопросов, их ID, порядок внутри тем и метаданные.
- Добавлены 230 самостоятельных открытых вопросов: по пять для каждого из 19 модулей C# и 27 модулей ASP.NET Core.
- Добавлены 25 специализированных тем; остальные вопросы дополнили существующие темы.
- Итого: 53 темы и 968 вопросов. Распределение по направлениям находится в `src/lib/topicFilters.ts`.
- Вопросы не содержат вариантов ответа, эталонных ответов или ссылок на недоступные примеры из теории. Необходимые короткие фрагменты кода приведены непосредственно в формулировке.
- Поле `block` содержит название модуля, `source` — стабильные ID курса и модуля для редакторской проверки. Источники не выводятся в пользовательском интерфейсе.
- Отметки знакомых вопросов сохраняются по ID; новые вопросы изначально не отмечены знакомыми. Начатый опрос сохраняет свой снимок вопросов.

Редакторский набор и повторяемое применение: `scripts/expand-open-catalog.mjs`. Запуск: `node --experimental-strip-types scripts/expand-open-catalog.mjs`. Скрипт идемпотентен для этой партии и проверяет сохранность прочих вопросов. При будущих изменениях опубликованного набора нужно повышать revision.

Каталог открытых вопросов обновляется отдельно от пакетов курсов. Текущий удалённый адрес настроен в `src/lib/content.ts` и указывает на GitHub `main/src/data/questions.json`. Изменения подготовлены локально; публикация в GitHub и новая сборка APK в рамках этой задачи не выполнялись.
