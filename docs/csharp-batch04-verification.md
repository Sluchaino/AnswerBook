## Ограничения и границы работы

Семь механик: matching **7**, sequence **5**, code-order **8**, code-debug **15**, data-transform **4**, code-trace **18**, architecture-builder **5**. Всего **62**.

Готовые снимки не являются отладчиком. Для LOH явно оговорены обычные настройки Runtime, pinning не обещает ускорение, CompactOnce не запускает GC немедленно. Исполнение примеров остаётся инструментом разработчика; приложение не компилирует код пользователя. Эталоны доступны офлайн, поэтому задания не предназначены для защищённого экзамена.

Из прежнего аудита остаются пересечения демо m02/m04/m11 и редакционная оговорка m05 о порядке написания метода. Они зафиксированы в карте покрытия; без новой технической ошибки старые задания не изменялись. Других функций и новых механик нет. **APK не пересобирался.**
