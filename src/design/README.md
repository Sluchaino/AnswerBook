# Дизайн AnswerBook

С версии Android 1.26 используется оформление Studio: холодный светлый фон, синий акцент, графитовая тёмная тема, заголовки Golos Text без курсива, округлые карточки и плавающая нижняя навигация.

Предыдущий зелёный дизайн 1.25 сохранён до изменений в `design-history/classic-1.25/classic-1.25-source.zip`. Инструкции и контрольные суммы находятся рядом с архивом. По просьбе «вернуть старый дизайн» используйте именно этот снимок, сохранив более новые данные и функциональность.

`studio.css` подключается после базовых стилей. Цвета существующих компонентов сопоставляются с семантическими токенами `--ui-*`, чтобы диалоги и выпадающие списки в порталах тоже поддерживали обе темы. Селекторы с `data-design` учитывают динамическое подключение мобильных стилей. Экспорт и печать используют прежние стили. Дизайн активируется через `data-design="studio"` в main.tsx; адаптация раскладки — через `data-layout` в App.tsx.

Мобильная шапка остаётся компактной. В версии 1.27 блок запуска опроса закрепляется под мобильной шапкой при прокрутке вниз; на компьютере закрепляется боковая карточка запуска. Управление прохождением остаётся вверху. Нижняя навигация содержит каталог, курсы и личный кабинет; под будущий баннер зарезервировано 112 px над панелью. Выбор темы сохраняется на устройстве. Нативные цвета Android согласованы в AppearancePlugin.java, styles.xml и capacitor.config.ts с theme.ts.
